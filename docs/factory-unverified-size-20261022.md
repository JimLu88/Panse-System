## 01执行入口（04不执行发送）

在群晖API容器运行 `python -m app.cli.factory_size_delivery --output /tmp/factory-size-retry-20261022.json`。默认只读，输出全部当前缺尺寸候选及排除理由，ready仅包含旧尺寸失败且原硬门通过的行。

核对精确范围后运行 `python -m app.cli.factory_size_delivery --apply --manifest /tmp/factory-size-retry-20261022.json`。执行前重核SKU、子单、数量、工厂号、尺寸、备注指纹；发生变化拒绝。已发送/未知/在途跳过，复用原子占位发送器，只传清单子单，不重置状态或清理历史证据。

执行后读回图消息ID/归档和原工厂表同步结果；消息送达、表同步、人工微信转发各自是独立事实。没有真实message_id不能称为补发成功。
