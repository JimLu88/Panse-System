# 产品表逐款淘宝链接

产品精选视图、全部列及展开SKU均展示只读淘宝链接。商品行可包含多个当前商品链接；精确款式链接使用同一PricingSkuPromo行的taobao_item_id和taobao_sku_id。历史备用ID不参与拼接。

缺SKU时只提供明确标注的商品级链接；缺商品ID、非法ID、SKU跨编码冲突或多商品歧义不得猜配。链接只接受数字ID并固定淘宝域名，新页打开，不改变价格、库存、订单、财务或平台商品。用户原自定义列视图仍保留，新增链接列始终可见。

关系流程已登记product.taobao_links及规格身份影响边。已有其他来源指纹漂移继续保留，未全量重锁冒称审核完成。
