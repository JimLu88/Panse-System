# 工厂制作单搜索与子单编号修复

2026-10-10 用户授权修复并按正式流程发布。

## 变更与边界

工厂制作单原搜索仅匹配产品字段，输入订单号会返回空。现在支持订单号、有效子订单号、工厂号和原产品字段，去除搜索前后空格。

工厂编号从导入的有效生产子单只读投影；排除退款、关闭、已发货、非生产和母单汇总行。多个编号全部显示，单值 factory_no 仅在唯一编号时返回；排序使用编号列表首项。只有没有导入子单时兼容旧母单编号，不写回母单。不改变原在制筛选、延期、数量、库存、价格、推送和发货逻辑。原编辑/重推操作仍按母单身份，未扩展为逐子单操作。

- 搜索/身份回归 5 项，以及客户延期、发货备注回归共 29 项通过。

- 前端沿用 order_label 的卡片、打印、导出路径，补充多编号排序和搜索提示。
