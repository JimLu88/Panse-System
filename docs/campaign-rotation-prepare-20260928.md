# 9条轮换后整批条件式制表入口

维护只交付程序，03负责执行一次prepare；没有上传、平台读取、导出或报价修改。固定母版不变。

## 使用

在 `D:/AI/畔色ERP系统/ERP程序`：

```powershell
# 只读计算并核源文件，表格只在内存里，不占用制表登记。
python scripts/campaign_rotation_prepare.py
# 确需制表时只调用一次，输出目录须不存在。
python scripts/campaign_rotation_prepare.py --output-dir <本轮新的整批交付目录>
```

输出同一轮全部文件和receipt.json：

- 活动表：床14条、岩板桌7条，旧9替新9，其余未轮换行不漏；包含岩板桌2定制修正。
- 单品立减新9条：沿固定价格版本，不改ERP日常价/中促目标，不拿商品导出G替活动P。
- 圆弧4条：由于撤出和无叠加模式未证明，独立HOLD表，不能连带阻挡新9，也不能把HOLD叫可上传。
- 4条缺P及额外全店范围集中列在回执，不填零、不拿G代P。

全部文件是**条件式准备**，upload_ready=false；新入口无放行或上传操作。03必须把具体条件一并交付，不能只发xlsx说已报名。
