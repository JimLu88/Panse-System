# 原批失败报告接续（2026-09-15）

原终态 SHA、claim、批次、原文件、SKU 全集及原价格保持不变。读取器兼容
source_report/source_report_sha256 与旧 official_report_path/official_report_sha256。
两组字段同时存在且冲突时拒绝，不能修改原终态来修路径。

仅原文件确实不存在时，按原活动完整身份和批次计算固定 feedback job ID，
只读取已 finished/downloaded 的原报告回执。替代文件必须与原终态固定的报告 SHA
完全一致，实际文件也要通过 SHA 与允许目录校验；不能使用不同版本、其他活动、
未完成下载或任意路径。该机制不会下载、上传、解锁或重放 claim。

Web-Agent 既有 recover-price-report 接口可将这种完整证据接回原已完成连续请求。
只允许一个确定的历史失败段，排除成功和未知动作，恢复当前授权范围内失败商品；
其他失败商品及其他活动段保持不变。后续仍由原连续程序按冻结规则分类、修正和提交。

“该商品需要包邮”是明确的包邮承诺缺项，显示为 free_shipping_commitment_required，
不是报告截断或价格异常。解析不授权包邮，不改表格包邮字段，不自动增加运费承诺。
原材料未能证明已有包邮时，等用户确认；其他独立商品继续。

本地回归通过不等于平台报名成功，业务结论只以原请求恢复后的官方终态为准。
