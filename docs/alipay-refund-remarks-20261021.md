# 支付宝退款与差价备注识别

支持差价、退差价、价保、价格保护、售后退款、退款、退钱、退还货款、退回货款、赔付、赔偿、补偿、售后。
完整18或19位订单号可以位于备注任意位置；不从更长支付流水号截取订单。
重复同一个订单号可识别，不同订单号、结构化字段与备注冲突或备注金额与实际支出不同均保留待核对。
金额只采用支付宝实际负数流水；正数不生成客户补偿。备注原文和原支付渠道关联号保留，派生平台订单号只补空。

CSV/个人流水和Excel入口共用解析。主力号沿用原个人支付宝售后关联账，自动导入只处理本轮新流水；其他入口继续既有范围。
差价补偿属于独立站外支出：明确备注旧订单完整编号时，允许挂到已取消旧订单，适用于退旧单重拍后的差价补偿；姓名推断不允许此例外。
不自动改旧订单或新订单的状态、实付及平台退款额，不推断新旧订单配对，不重放历史流水。
关联账是主力号售后备注的唯一写入者。已确认关联、人工标记、金额冲突、多单不重复自动入账，待核对款不转采购。
确认前再读当前备注和实付，过期候选不能自动确认。沿用既有客户赔付类型保存明确退款，展示为客户退款/赔付，不新增数据库枚举。

验证包含任意位置、关键词、实际金额、长流水号、冲突、多单、CSV/Excel导入、取消旧单、完整入账与幂等。
