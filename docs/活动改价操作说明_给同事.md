# 活动改价操作说明（现行）

> 旧版“活动价与单品立减二选一”的说明已经作废。现行唯一口径见：
> [淘宝活动报名价格_唯一逻辑.md](./淘宝活动报名价格_唯一逻辑.md)。

给同事操作时只记住四句话：

1. 真 SKU 的活动报名价永远填 ERP 日常价。
2. 官方立减和单品立减必须叠加。
3. 到手价 = 活动报名价 − 官方立减 − 单品立减。
4. 报完必须导出最新“已报商品”和单品立减记录逐 SKU 核对，全部一致才算完成。

场次区别：

- 超级立减：官方 10%，对齐 ERP 中促目标。
- 88VIP、狂暑季等普通大促：官方 12%，对齐 ERP 大促目标。
- 618、双11：官方 15%，对齐 ERP 大促目标。

定制占位 SKU 使用系统保护报名价且不叠单品立减。任何错活动、错价、缺 SKU、
批量操作失败或平台规则不符，都应立即停止并查看飞书错误报告，不要自行降价。
