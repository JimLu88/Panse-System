# 畔色 · 淘宝活动改价操作说明（给同事）

> 一句话：**到手价 = 日常价 − 官方立减 − 单品立减**（淘宝是"加法"，两刀各自从活动价里减）。
> 系统「活动报名表」已经把每个 SKU 该填的数都算好了，照着填即可。

## 一、三种活动，对应三个目标价（先记住）

| 活动场次 | 官方立减力度 | 目标到手价 | 要不要换 SKU |
|---|---|---|---|
| 日常（超级立减） | **10%** | 中促价 | 否 |
| 88VIP 大促 | **12%** | 大促价 | 否 |
| 618 / 双11 | **15%** | 大促价（同价） | **是**（换无历史新规格） |

## 二、价格是怎么一层层下来的

1. 标价 × 0.75（**单品宝，固定一直打**）= **日常价**（= 淘宝里的活动价）。
2. 活动期，淘宝按**加法**再减两刀：**到手 = 日常价 − 官方立减 − 单品立减**
   - 官方立减 = 日常价 × 力度（各场固定 10% / 12% / 15%，平台自己减）。
   - 单品立减 = 我们自己在淘宝「单品立减 / 单品补贴」里再叠的那部分。

## 三、单品立减该填多少（核心）

在系统「定价总表」页点 **「活动报名表」** 按钮，导出带图的 Excel，一个 SKU 一行，直接照填：

- **单品立减**：填「XX单品立减(折)」列的**折**（如 `7.92` 折），或用「XX立减(元)」列的**立减金额**（更精确，到分）。**二选一**。
- **报名价**（填淘宝超级立减 / 官方大促报名表里的活动价）：填「88VIP大促报名价」或「超大促报名价(618/双11)」列。
- 某档是空格 = 该档官方立减已经够了，不用再叠单品立减。

公式（供理解，不用手算）：**单品立减折 = 目标到手 ÷ 日常价 + 官方力度**。
所以**每换一个活动力度，单品立减都要重填**（力度越深，单品立减打得越浅）。

## 四、举例（1.2 米黑胡桃餐边柜）

- 日常价（活动价）**19575**，目标大促到手 **13153**。
- **大促（88VIP 12%）**：官方立减 2349（=19575×12%）+ 单品立减 **7.92 折 / 减 4073 元** → 到手 **13153** ✅
- **618（15%）**：官方立减 2936 + 单品立减 **8.22 折 / 减 3486 元** → 到手仍 **13153**（同价）✅
- ⚠️ 之前填成 8.1 折 → 单品立减只减了 3719 → 到手 13506，比目标高了 353 元。**别再照 8.1 折，按报名表给的数填。**

## 五、三条红线

1. 报活动只填「单品立减 + 报名价」，**别自己再乱叠别的打折工具**。
2. 单品立减做价**不能低于「空档价红线」（= 中促到手）**，否则砸穿淘宝近 15 天最低价线，下个大活动报不进（要 15 天才洗回）。
3. **只有 618 / 双11 要换 SKU**（新规格无价格历史，才能报 15% 深折）；日常和 88VIP 大促**不用换、也不用动**。

---
*口径依据：淘宝官方大促「官方立减 + 单品补贴」两刀加法（2026-07-06 后台实测核准）。数值由系统 `活动报名表` 自动生成，改大促基数后会自动重算。*
