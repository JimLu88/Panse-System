# 畔色 · 淘宝活动改价操作说明（给同事）

> 一句话：**到手价 = 日常价 − 官方立减 − 单品立减**（淘宝是"加法"，两刀各自从活动价里减）。
> 系统「活动报名表」已经把每个 SKU 该填的数都算好了，照着填即可。

## 一、三种活动，对应三个目标价（先记住）

| 活动场次 | 官方立减力度 | 目标到手价 | 要不要换 SKU |
|---|---|---|---|
| 日常（超级立减） | **10%** | 中促价 | 否 |
| 88VIP 大促 | **12%** | 大促价 | 否 |
| 618 / 双11 | **15%** | 大促价（同价） | **是**（换无历史新规格） |

## 二、价格是怎么一层层下来的

1. 标价 × 0.75（**单品宝，固定一直打**）= **日常价**（= 淘宝里的活动价）。
2. 活动期，淘宝按**加法**再减两刀：**到手 = 日常价 − 官方立减 − 单品立减**
   - 官方立减 = 日常价 × 力度（各场固定 10% / 12% / 15%，平台自己减）。
   - 单品立减 = 我们自己在淘宝「单品立减 / 单品补贴」里再叠的那部分。

## 三、怎么填（核心）—— ★两种填法「二选一，千万别混」

在系统「定价总表」页点 **「活动报名表」** 按钮导出，一个 SKU 一行。有**两种**填法能到同一个目标到手价，**只能用一种，绝不能又填报名价当活动价、又叠单品立减**（那会打两次折、价格砸穿）：

**方法 ①（常规·推荐）——「活动价填日常价 + 单品立减」**
- 淘宝**活动价** = 报名表「**日常价(活动价)**」列（如 19575）。
- **单品立减** = 「XX立减(元)」列的**立减金额**（如 减 4073，更精确），或「XX单品立减(折)」列的**折**。
- 官方立减（日常10% / 88VIP大促12% / 618双11 15%）平台自动扣 → 到手 = 各档「到手」列。

**方法 ②——「活动价直接填报名价，不叠单品立减」**（主要给 618 换 SKU 用）
- 淘宝**活动价** = 「88VIP大促报名价」或「超大促报名价(618/双11)」列（这数**已经把官方立减算进去了**）。
- **单品立减 = 0 / 不填**。光靠官方立减就到目标到手价。

> 某档单品立减是空格 = 官方立减已经够，不用叠。

## 四、举例（1.2 米黑胡桃餐边柜，目标到手 13153）

- **方法①**：活动价填 **19575**（日常价），单品立减填 **减 4073 元** → 19575 − 官方12%(2349) − 4073 = **13153** ✅
- **方法②**：活动价填 **14947**（88VIP大促报名价），单品立减 **不填** → 官方12% → 14947×0.88 = **13153** ✅
- ❌ **踩过的坑**：活动价填了 14947（报名价）**又叠了** 8.1 折单品立减 → 14947 − 1794 − 2840 = **10313**，比目标低了 2840。**这就是"两种混填、折两次"。**

## 五、三条红线

1. **两种填法二选一，绝不混**（别"活动价填报名价"又"叠单品立减"）。
2. 单品立减做价**不能低于「空档价红线」（= 中促到手）**，否则砸穿淘宝近 15 天最低价线，下个大活动报不进（要 15 天才洗回）。
3. **只有 618 / 双11 要换 SKU**（新规格无价格历史，才能报 15% 深折）；日常和 88VIP 大促**不用换、也不用动**。

---
*口径依据：淘宝官方大促「官方立减 + 单品补贴」两刀加法（2026-07-06 后台实测核准）。数值由系统 `活动报名表` 自动生成，改大促基数后会自动重算。*
