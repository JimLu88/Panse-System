# 畔色 ERP — AI 客服系统 对接文档（只读集成 API）

> 给独立的「AI 客服系统」读取畔色主系统的 **产品 / 价格 / 尺寸 / 订单** 等信息。
> 全部**只读**，不会改主系统任何数据。版本 v1（2026-06-15）。

---

## 1. 基本信息

| 项 | 值 |
|---|---|
| Base URL | `http://192.168.31.21:8200`（群晖内网；外网另配） |
| 路径前缀 | `/api/cs` |
| 鉴权 | 请求头 `X-API-Key: <密钥>` |
| 密钥来源 | 管理员在主系统生成 `cs_api_key`，**找管理员要**（不要写进代码仓库/截图外发） |
| 返回格式 | JSON（UTF-8，中文直接返回） |

**鉴权返回码**：密钥未配置 → `503`；缺/错 `X-API-Key` → `401`。

自测连通：
```bash
curl -H "X-API-Key: <密钥>" http://192.168.31.21:8200/api/cs/ping
# 200 {"ok":true,"service":"panse-cs-integration","version":1}
```

## 2. 接口清单

### 2.1 产品搜索/列表 `GET /api/cs/products`

| 参数 | 说明 |
|---|---|
| `q` | 模糊搜产品码/名称（可选） |
| `category` | 按类目精确筛，如「餐厅-餐桌」（可选） |
| `limit` | 默认 50，最大 200 |

```bash
curl -H "X-API-Key: <密钥>" "http://192.168.31.21:8200/api/cs/products?q=餐桌&limit=20"
```
```jsonc
{
  "count": 12,
  "products": [
    {
      "code": "PPS26330150118",
      "name": "畔色黑胡桃木悬浮双人床",
      "category": "卧室-床",
      "custom_scope": "长度支持2100mm内定制；高度支持950mm内定制",
      "size": { "width": 1250, "length": 2100, "height": 950 },  // 解析自 size_detail(mm)，解不出为 {}
      "size_detail": "宽度：1250mm；长度：2100mm；高度950",        // 原文，含解不出的「暂无」等
      "image_url": "https://item.taobao.com/item.htm?id=...",
      "taobao_id": "123456789",
      "prices": {
        "sku_count": 3,
        "list_price_min": 4980, "list_price_max": 6580,   // 标价区间
        "daily_price_min": 4680, "daily_price_max": 6280  // 日常价/单品宝区间
      }
    }
  ]
}
```

### 2.3 订单查询 `GET /api/cs/orders`

`order_no` 与 `customer` **二选一必填**。

| 参数 | 说明 |
|---|---|
| `order_no` | 精确淘宝订单号 |
| `customer` | 客户名（模糊） |
| `limit` | 默认 50，最大 200 |

```bash
curl -H "X-API-Key: <密钥>" "http://192.168.31.21:8200/api/cs/orders?order_no=3061974901843987868"
```
```jsonc
{
  "count": 1,
  "orders": [
    {
      "order_no": "3061974901843987868",
      "customer_name": "北京 霓蓝蓝",

      "sku": "...", "qty": 1,

      "order_date": "2025-12-10",

      "refund_status": null
    }
  ]
```

## 3. 重要说明 / 当前边界

- **尺寸**：来自产品的 `size_detail` 文本，系统尽力解析成 `size.{length,width,depth,height}`(mm)。约 54% 产品可解析，其余原文是「暂无」等 → `size` 为 `{}`，以 `size_detail` 原文为准。
- **知识库**：主系统**没有独立的客服 FAQ/知识库**（内部 `ai_knowledge` 是 AI 异常解决库、且为空）。**产品详情（定制范围 `custom_scope`、主辅材、文案 `description`、尺寸）就是产品知识来源**。
- **定制估价（计算/预估价格）**：标准款价格用 §2 的 `list_price/daily_price`。**完全定制的逐板报价引擎需要板级输入（每块板材料/尺寸/数量），v1 暂不开放**；如确需程序化定制估价，把要传的字段列给主系统侧，再开 `POST /api/cs/quote`（v2）。
- **图库**：v1 在产品详情给 `image_url` / 主图相对路径。**「按部位/特写标签筛选图片」要等客服系统给图片打标完成后再开**（v2，届时加 `GET /api/cs/gallery?code=&tag=`）。图库文件服务的 URL 规则另行同步。
- **只读**：本套接口不提供任何写操作。

## 4. 给主系统管理员（设置密钥，只需一次）

在群晖 api 容器执行（生成并查看密钥；密钥只发客服开发，勿进仓库/截图外发）：
```bash
sudo /usr/local/bin/docker exec -i panse-system-api-1 python - <<'PY'
import secrets
from app.database import SessionLocal
from app.services import settings_service
db=SessionLocal()
k=settings_service.get(db,"cs_api_key",env_fallback=False) or ("cs_"+secrets.token_urlsafe(24))
settings_service.set_value(db,"cs_api_key",k); db.commit()
print("cs_api_key =", k)
db.close()
PY
```
换密钥：先把 `cs_api_key` 置空再重跑。
