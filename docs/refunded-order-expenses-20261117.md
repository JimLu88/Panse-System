# 已确认退回订单的费用统计

全额退款且 `AfterSales.second_inbound_confirmed=已确认` 的非补单订单纳入逐单核对及统一利润统计，仍不计入真实成交数量。按原订单月份归属。

退回商品不再次计作销售成本；原实际打包、实际发货物流、实际安装以及退款外售后费用分别计入。没有实际值不使用整件估值；税费、平台费保留原财务函数及人工核定值。此变更不确认入库、不修改商品库存、不写订单金额、不触发付款或飞书通知。未确认入库和部分退款不进入本次专用分支。

用户核定案例 5067945110722719629：收入2674.41，退款2674.41，原打包260、物流315、安装66、售后705.10，平台和税为0；费用合计1346.10，净利-1346.10。

关系影响审查：`finance.actual / finance.freight / after.return / after.payment -> finance.profit`。逐单核对和导出均使用同一报表数据；普通成交、补单、推广、固定成本保持原规则。API报表及前端页面仍有未建模的静态引用候选，不能把关系指纹当业务验收。普通订单在统一利润汇总中继续使用原来的成本估值调用方式，只有已确认退回分支读取数据库入库证据。

回归覆盖：费用分别入账、月度合计、原成交数量不增加、部分退款/未确认入库不进入该分支、原成本拆分及导出回归。发布后须读取正式订单报表及月度统计验证。
