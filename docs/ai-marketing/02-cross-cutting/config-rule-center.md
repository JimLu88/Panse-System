# 横向 Ⅰ · 配置与规则中心

> 状态：📝 设计稿

## 职责（一句话）

把所有**易变的东西集中起来**，可热更新、可灰度。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **敏感词分级熔断** | S 级自动熔断 / A 级强制人工确认 / B 级仅预警 |
| **官方规则模板** | 预配置"小红书美妆模板""TikTok 美国区模板"，用户一键导入 |
| **规则版本控制 + 热更新沙盒** | 新一批敏感词先 5% 低权重测试账号灰度，确认无误再全量 |
| **平台规则监听** | 每日抓平台社区规范更新，提前 72 小时预警变化 |
| **模板社区** | 用户分享自创模板，形成生态 |

---

## 关键设计决策

### 1. 敏感词分级熔断

| 等级 | 处理 | 示例 |
|---|---|---|
| **S 级** | 自动熔断，不可发 | 第三方平台名 / 违禁品 |
| **A 级** | 强制人工确认 | 极限营销话术 / 绝对化用词 |
| **B 级** | 仅预警，可跳过 | 主观夸张词（"超好用"等） |

**为什么**：一刀切的敏感词库不可用——会过度拦截，运营员失去信任。

### 2. 规则版本控制 + 沙盒灰度

```
   新规则提交
        ↓
   v0.X.0 沙盒（5% 测试账号）
        ↓
   24h 观察期 → 拦截率 / 误杀率
        ↓
   通过 → v0.X.1 全量    失败 → 回滚
```

**为什么**：敏感词错杀一篇内容损失不大，错杀一个账号的全部内容是灾难。

### 3. 平台规则监听

每日自动抓取各平台社区规范页面，diff 对比昨日版本：
- 有新增 → 提前 72h 推送预警
- 有删除 → 评估是否放宽内部规则

**为什么**：平台规则变化是封号头号杀手。被动响应不如主动监听。

### 4. 配置热更新（不重启）

所有运行时配置（敏感词 / 折叠线 / 人格词典）支持热加载：
- 服务不停
- 已生成的稿件不重新生成
- 下一篇生成立即生效

### 5. 模板社区

用户可创建并分享模板：
- 平台模板（小红书美妆 / TikTok 美区）
- 风格模板（油痘肌测评 / 旅行 vlog）
- Prompt 模板（hook 库 / cta 库）

形成生态，复用降本。

## 输入 / 输出

**输入**：人工编辑 / 平台规则抓取 / 模板社区上传
**输出**：实时配置流推送给所有子系统

## 与其他子系统的接口

被所有子系统订阅：

- ① → 选题策略规则
- ② → 风格 DNA 抽取参数
- ③ → 生成 prompt 模板 + 合规规则
- ③.5 → 审核阈值 + 改写模板
- ④ → 平台人格词典 + 折叠线
- ⑤ → 健康阈值规则
- ⑥ → driver 配置 + 反共振参数
- ⑦ → 真实感公式系数

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 配置变更打破生产 | 沙盒灰度 + 一键回滚 |
| 规则膨胀，谁都不知道有哪些 | 规则树状视图 + 命中分析 |
| 模板社区被恶意污染 | 模板审核流程 + 用户评分 + 黑名单 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 敏感词分级（S/A/B）+ 热加载
- ✅ 平台模板（小红书等）的初始版
- ✅ 规则版本控制（git-style）

**MVP 不做**：
- ❌ 沙盒灰度（先全量上）
- ❌ 平台规则自动监听（先人工跟进）
- ❌ 模板社区开放（先内部用）
