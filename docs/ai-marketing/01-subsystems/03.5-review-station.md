# ③.5 人工审核工位

> 状态：📝 设计稿
> ⚠️ 一等公民——这是 ROI 决定性环节，**不是补丁**。

---

## 职责（一句话）

让单篇审核压缩到 **≤ 30 秒**。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **三张体检报告** | AI 感评分 / 违禁词命中清单 / 与参考爆款骨架重复度 |
| **差异化高亮 + 一键操作** | 左侧问题高亮，右侧三个改写版本备选 |
| **Diff 反馈循环** | 人工修改自动留痕，反哺账号 prompt 负向词库 |
| **必改 3 节点强制确认** | 首图文字 / 第二段营销话术 / 个人化细节，5 秒过 |
| **多人协作 + 责任追溯** | 谁审过、改了什么、何时通过，永久留痕 |

---

## 关键设计决策

### 1. 量化三张体检报告

| 报告 | 形态 | 阈值 |
|---|---|---|
| AI 感评分 | 0–100，越低越像人 | ≥ 70 → 阻塞 |
| 违禁词清单 | S/A/B 三级分类 | S 级直接拒绝 |
| 骨架重复度 | 与历史爆款的结构匹配 | > 60% → 强制变体 |

**为什么**：审核员靠"感觉"看不准、看得慢、不稳定。量化才能 5 秒判定。

### 2. 左高亮 + 右三改写

UI 设计原则：

```
┌──────────────────────────┬──────────────────────────┐
│ 原文（问题高亮）           │ 改写版本 1                 │
│                          │ 改写版本 2                 │
│ "[最低价]全网最低"⚠️A级    │ 改写版本 3                 │
│                          │ [手动改写]                 │
└──────────────────────────┴──────────────────────────┘
                       [通过] [拒绝]
```

**为什么**：审核员看到问题 → 点一下右侧候选就替换 → 30 秒完成。

### 3. Diff 反馈循环

每次人工修改记录为 `(原文 → 新文)` 的 Diff。当一个账号在 30 天内：
- 同一个词被删除 ≥ 5 次 → 进入该账号 prompt 的负向词库
- 同一句式被改写 ≥ 3 次 → 标记为该账号风格忌讳

**为什么**：审核员的隐性知识必须被系统抓住，否则永远在重复劳动。

### 4. 必改 3 节点强制确认

每篇审核屏幕上**永远高亮三处**，必须勾选才能"通过"：

- ☐ 首图文字 OK
- ☐ 第二段营销话术 OK
- ☐ 个人化细节足够

**为什么**：这三处是质量 80/20 的 80。其余靠抽查即可。

---

## 输入 / 输出

**输入**：来自 ③ 的草稿对象
**输出**：通过的稿件 → ④ 适配 / 拒绝的稿件 → 回 ③ 重写

人工修改产生的 Diff → 反哺到对应账号的 prompt 模板。

---

## 与其他子系统的接口

- **← ③**：接收草稿
- **→ ④**：通过稿进入平台适配
- **→ ③（反向）**：拒稿 + 拒稿原因回到生成引擎
- **→ 配置中心**：把 Diff 反哺写入账号 prompt 负向词库
- **→ 风控总线**：连续多次某模板被改 → 告警

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 审核员图省事一律通过 | 抽查机制 + 通过后 24h 数据回归检查 |
| 改写版本不够用 | 配置中心提供改写模板池 + 一键调多 LLM 重新生成 |
| Diff 反哺过度（把好词也删了） | 反哺前人工确认 + 频次阈值 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 三张体检报告（量化）
- ✅ 左高亮 + 右三改写
- ✅ 必改 3 节点强制勾选
- ✅ Diff 留痕（先不自动反哺）

**MVP 不做**：
- ❌ Diff 自动反哺到 prompt 负向词库（积累一批 Diff 后人工评估再做）
- ❌ 多人协作的并发审核分配
