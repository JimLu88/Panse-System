# ② 素材采集与分析层

> 状态：📝 设计稿

## 职责（一句话）

学别人怎么做的，但**只学结构和风格，不存原文**。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **多源素材输入** | 公开数据、订阅、本地爬虫接口（挂载项 A） |
| **结构化风格 DNA** | 强制 JSON 输出，永不存原文 |
| **3 要素脱敏** | 品牌名/人名/具体型号一律替换为泛化标签（`[口红品牌][色号]`），仅保留结构 |
| **风格 Embedding 向量化** | 建立"风格 DNA 库"，生成时按风格 ID 秒级调取 |
| **反抄袭采样** | 采集样本相互相似度 >30% 自动剔除，防止学到同一篇的回声 |

---

## 关键设计决策

### 1. 强制 JSON 输出，永不存原文

风格 DNA 强制输出为如下结构：

```json
{
  "sentence_length_avg": 15,
  "emoji_frequency": 0.12,
  "question_ratio": 0.25,
  "first_person_ratio": 0.6,
  "hook_type": "pain_point",
  "structure_pattern": "problem-solution-case",
  "vocabulary_level": "middle",
  "emotion_tone": "friendly",
  "transition_words": ["但是", "其实", "没想到"],
  "ending_type": "call_to_action",
  "tag_count": 8,
  "paragraph_length_avg": 3
}
```

**为什么**：
- 法律风险：不存原文就不存在版权问题
- 同质化风险：存了原文容易被生成时直接复用，导致矩阵号同质
- 资产沉淀：JSON 化的风格才能向量化、做 A/B、做匹配

### 2. 3 要素脱敏

采集时强制把品牌名 / 人名 / 具体型号替换为泛化标签：

| 原文 | 脱敏后 |
|---|---|
| "雅诗兰黛 412" | "[口红品牌][色号]" |
| "李佳琦推荐" | "[头部带货博主]推荐" |
| "iPhone 15 Pro" | "[旗舰手机型号]" |

**为什么**：从源头规避商业合规问题；让风格学习专注于"如何表达"而非"在表达什么"。

### 3. 反抄袭采样

任意两个采集样本之间计算文本相似度（simhash / minhash），>30% 阈值自动剔除一个。

**为什么**：如果采集的 50 篇里有 30 篇是互相搬运的，模型会过拟合到那一篇的表达，反哺生成时就成了"二次抄袭"。

## 输入 / 输出

**输入**：
- 来自 ① 的选题 + 参考样本 URL 列表
- 挂载项 A（本地爬虫）输出的原始内容
- 公开 API 数据流

**输出**：
- 风格 DNA JSON（写入风格 DNA 库）
- 结构骨架（hook → pain → solution → case → cta 这种模式）
- 风格 Embedding 向量（写入向量库供 ③ 检索）

---

## 与其他子系统的接口

- **← 挂载项 A**：标准接口接入本地爬虫
- **← ①**：接收选题 + 参考样本
- **→ ③**：风格 DNA + 结构骨架供生成
- **→ 风格 DNA 库**：持久化风格资产

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 模型抽取的风格 JSON 不稳定 | 多次抽取取平均 + 关键字段做硬约束 |
| 脱敏不彻底，泄漏到生成稿 | 双层过滤：采集时脱敏 + 生成后再扫一遍 |
| 风格库越来越大无法检索 | 向量化 + 按品类分库 + 定期归档低频风格 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 接入挂载项 A（已有本地爬虫）
- ✅ 强制 JSON 输出 + 3 要素脱敏
- ✅ 基础风格 DNA 抽取

**MVP 不做**：
- ❌ 风格 Embedding 向量化（规模化阶段做）
- ❌ 多模态风格抽取（配图风格、视频节奏）
