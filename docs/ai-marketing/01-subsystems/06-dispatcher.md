# ⑥ 分发调度中心

> 状态：📝 设计稿

## 职责（一句话）

决定**什么内容、什么时候、用哪个号、发到哪**。

---

## 核心架构：统一接口 + 可插拔 driver

```
publish(content, account)
        │
        ├─→ api_driver         （海外官方 API，默认启用）
        ├─→ assist_driver      （人工提醒+剪贴板，国内默认）
        ├─→ automation_driver  （模拟操作，默认关闭，挂载项 D）
        └─→ ... 未来三方扩展
```

**为什么**：所有 driver 实现同一接口，分发逻辑无感知。换 driver 不需要改业务代码。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **双模无缝降级** | API 连续 2 次失败/限流 → 自动降级 ASSIST + 通知 |
| **双模升级** | 国内号拿到企业 API → 可升级 AUTO |
| **沙盒预发** | 正式发布前在观察号或测试环境跑一遍，通过才入正式队列 |
| **反共振发布算法** | 同选题多账号强制错峰（23 分钟 / 47 分钟级别随机抖动）+ 标签交叉打散 |
| **ASSIST 防手滑** | 提醒弹窗显示今日已发 X 篇 / 上限 Y 篇，确认发布 10 秒倒计时 |
| **沉浸式发布工作台** | 移动端 App / 桌面深度链接，唤起目标 App 自动粘贴图文，30 秒/篇 |
| **剪贴板管道化** | 浏览器插件 Alt+1/2/3 依次切换 标题 / 正文 / 标签 |

## 关键设计决策

### 1. 双模无缝降级

```
   API driver
   ├─ 第 1 次失败 → 重试
   ├─ 第 2 次失败 → 降级到 ASSIST
   │                 ↓
   │              通知人工 + 切换今日所有该平台任务
   └─ 限流告警 → 立即降级
```

**为什么**：自动失败不要默默崩，而是优雅降级。

### 2. 沙盒预发

```
   适配后的稿件
        ↓
   沙盒环境（观察号 / 测试账号 / 干跑模式）
        ↓
   检查：图片完整性 / 文案合规 / 敏感词 / 渲染正常
        ↓
   通过 → 正式队列    失败 → 回 ③.5 / 告警
```

**为什么**：不在主力号上做"实验"。烧号代价大。

### 3. 反共振发布算法

同一选题在 5 个号发布时：

```
   号 A: T+0
   号 B: T+23 分钟（+随机 0–60 秒）
   号 C: T+47 分钟
   号 D: T+1h12 分钟
   号 E: T+2h05 分钟
```

标签集合各自打散：
- 号 A 用 [a, b, c]
- 号 B 用 [a, d, e]
- 号 C 用 [b, e, f]
- ...

**为什么**：算法会识别"同选题同时间同标签"的共振，标记为矩阵号被降权。

### 4. ASSIST 沉浸式工作台

ASSIST 模式不应该让运营员痛苦。设计目标：

- **桌面端**：浏览器插件，Alt+1 切到标题剪贴板，Alt+2 正文，Alt+3 标签
- **移动端**：深度链接 + 通知，点击通知 → 唤起目标 App → 自动粘贴图文 → 人工微调 → 发
- **防手滑**：今日已发计数 + 10 秒倒计时

单篇压到 30 秒。

---

## 输入 / 输出

**输入**：来自 ④ 的适配后变体 + 来自 ⑤ 的账号清单 + 健康状态
**输出**：发布指令到 driver → 真实发布结果回写 ⑤ ⑦

---

## 与其他子系统的接口

- **← ④**：拉适配后稿件
- **← ⑤**：查可用账号 + driver 模式
- **→ ⑤**：写回发布结果
- **→ ⑦**：发布事件入分析管道
- **挂载项 C/D**：可插拔 driver

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| API 限流 / 配额耗尽 | 多 key 轮换 + 实时配额监控 + 自动降级 |
| ASSIST 模式人工漏发 | 提醒升级机制（5 分钟未确认推第二次） |
| 自动操作被检测 | 反共振 + 沙盒 + 挂载项 E（环境胶囊） |
| 沙盒漏检测 | 多维 checklist + 上线 24h 二次回归 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ `publish()` 统一接口
- ✅ `assist_driver` 实现
- ✅ 沙盒预发（基础版）
- ✅ 反共振调度

**MVP 不做**：
- ❌ `api_driver`（扩展阶段海外接入）
- ❌ `automation_driver`（评估阶段）
- ❌ 沉浸式工作台移动端（先做浏览器插件）
