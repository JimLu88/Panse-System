# ③ 内容生成引擎

> 状态：📝 设计稿

## 职责（一句话）

把**选题 + 素材 + 风格 DNA** 加工成**草稿**。这是系统真正的"智力中枢"。

---

## 四层流水线（核心结构）

```
   选题 + 风格 DNA + 事实素材
            │
            ▼
   ┌─────────────────────┐
   │ ①  逻辑重构层         │  把事实重组成新叙事框架
   │   （顶级模型）         │  例：产品测评 → 油痘肌自救日记
   └──────────┬──────────┘
              ▼
   ┌─────────────────────┐
   │ ②  事实核查层 ⚠️关键   │  提取所有事实声明，调搜索 API
   │   （廉价模型 + 搜索）  │  无法验证的高亮"待人工核实"
   └──────────┬──────────┘
              ▼
   ┌─────────────────────┐
   │ ③  风格注入层          │  套风格 DNA 配方
   │   （顶级模型）         │  控制句长/emoji/钩子类型
   └──────────┬──────────┘
              ▼
   ┌─────────────────────┐
   │ ④  合规预检层          │  敏感词分级 / AI 感评分
   │   （廉价模型）         │  信息密度评分
   └──────────┬──────────┘
              ▼
         草稿（含必改 3 节点标记）
```

---

## 关键设计决策

### 1. 事实核查层中间插入（不是事后补救）

**为什么**：模型幻觉是 ROI 杀手。事后核查改起来痛苦，前置核查可以让风格注入层只处理已验证事实。

事实声明示例：
- 数值类（"含量 5%"、"价格 199"）→ 搜索验证
- 引用类（"医生推荐"、"专家说"）→ 找原文
- 时间类（"上周发布"、"3 天前"）→ 时序校对

无法验证的标 `⚠️ 待人工核实`，进入审核工位高亮。

### 2. 多 LLM 分层调用

| 任务 | 模型 | 成本权重 |
|---|---|---|
| 清洗 / 格式化 / JSON 抽取 | DeepSeek / GPT-4o-mini | 0.1× |
| 事实核查 | GPT-4o-mini + 搜索 | 0.3× |
| 核心生成（逻辑重构、风格注入） | Claude / GPT-4o | 1.0× |
| 创意命题 / hook 创作 | 顶级模型 | 1.0× |

**为什么**：成本可降 60%+。详见 [llm-router.md](../02-cross-cutting/llm-router.md)。

### 3. 视觉一致性锚定

生图**不直接产出图片**，而是产出 ComfyUI / Flux 工作流参数：

- 固定 Seed 范围（一个号一个段）
- 固定 Lora 组合
- 固定排版标签

**为什么**：矩阵号的视觉统一是辨识度的核心，但又不能完全一样（会被算法识别为同号）。

### 4. 必改 3 节点强制标记

生成结果永远高亮三处：

1. **首图文字覆盖率** — 小红书/Ins 封面文字占比
2. **第二段营销话术** — 折叠线前后的转化点
3. **个人化细节密度** — "我"、"我家"、"上次"这类真实感锚

**为什么**：审核员只需 5 秒确认这三处，单篇审核能压到 30 秒。

## 输入 / 输出

**输入**：
- 来自 ① 的选题 + 推荐风格 ID
- 来自 ② 的风格 DNA + 结构骨架
- 来自 ⑤ 的目标账号性格档案（如已分配）
- 配置中心的合规规则

**输出**：草稿对象，包含：
- 文本内容（含必改 3 节点标记）
- 配图工作流参数
- 事实核查报告（已通过 / 待人工）
- 合规预检结果（S/A/B 级命中清单）
- 信息密度评分 + AI 感评分

---

## 与其他子系统的接口

- **← ①②⑤ 配置中心**：拉取生成所需要素
- **→ ③.5**：草稿进入人工审核工位
- **← Diff 反馈循环**：③.5 的人工修改自动 git-diff 反哺 prompt 负向词库
- **← 风控总线**：触发合规事件时直接拒绝生成

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 模型幻觉 | 事实核查层硬性插入 |
| 风格漂移（连续多次生成后偏移基准） | 每轮重新对齐风格 DNA，不基于上轮输出 |
| 多 LLM 路由切换造成风格断裂 | 风格注入层永远使用同一档模型 |
| 信息密度低（车轱辘话） | 信息密度评分 < 阈值自动重试 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 四层流水线完整骨架
- ✅ 多 LLM 路由
- ✅ 必改 3 节点标记
- ✅ AI 感评分 + 敏感词预检

**MVP 不做**：
- ❌ 视觉锚定 / ComfyUI 工作流（规模化阶段）
- ❌ 事实核查的企业知识库对接（先用搜索 API）
- ❌ 多轮自我修正（生成 1 次过审，超出则进审核工位）
