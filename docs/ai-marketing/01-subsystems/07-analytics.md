# ⑦ 数据回收与分析

> 状态：📝 设计稿

## 职责（一句话）

回收数据 → 反哺选题，闭环。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **真实感归因** | `0.4×提问评论率 + 0.3×用户间互动率 + 0.3×长评论占比` |
| **冷启动噪声过滤** | 新号 0.2 / 千粉号 1.0 / 万粉号 2.5 |
| **归因引擎** | 分析组合效果（"油痘肌+自救日记+3:4 封面"），而非单因素 |
| **行动建议生成** | 自动产出可执行建议 |
| **爆款指纹库** | 质量分超阈值的内容自动入库 |

---

## 关键设计决策

### 1. 真实感归因，而非阅读量崇拜

```
   真实感 = 0.4 × 提问评论率
          + 0.3 × 用户间互动率（评论互相回复）
          + 0.3 × 长评论占比（>15 字的评论 / 总评论）
```

**为什么**：
- 高赞低评论 = 算法推送但用户不互动 = 假爆款
- 真实感低的内容反哺到选题会带偏方向
- 真实感 < 0.6 自动推送人工复盘

### 2. 冷启动噪声过滤

来自不同体量账号的数据贡献权重不同：

| 账号类型 | 权重 |
|---|---|
| 新号（<1k 粉） | 0.2 |
| 千粉号 | 1.0 |
| 万粉号 | 2.5 |

**为什么**：新号偶然爆的笔记不能当作品类信号。否则会把整个矩阵带偏。

### 3. 归因引擎（组合分析，不是单因素）

不要分析"封面图是不是 3:4"这种单因素，而是分析组合：

```
   "油痘肌 + 自救日记 + 3:4 封面 + 7点发布"  → 真实感 0.82
   "油痘肌 + 评测对比 + 1:1 封面 + 7点发布"  → 真实感 0.41
```

**为什么**：单因素相关性是噪音，组合特征才有可操作性。

### 4. 行动建议自动生成

输出范例：
> 你的测评类互动低于均值 47%，建议增加真实使用场景（"上周用了 3 次"这种锚），并把发布时间从 9:00 后移到 7:30。

**为什么**：数据看板没用，行动建议才有用。

### 5. 爆款指纹库

质量分（真实感 × 阅读量×权重）超阈值的内容：
- 提取共同特征
- 入库索引
- 反哺到 ① 选题决策

---

## 输入 / 输出

**输入**：来自 ⑥ 的发布事件 / 各平台数据 API / 平台抓取
**输出**：真实感分数 + 行动建议 → 推送 ① ③ ⑤ / 爆款指纹 → ①

---

## 与其他子系统的接口

- **→ ①**：选题反哺
- **→ ③**：prompt 模板效果反馈
- **→ ⑤**：账号画像更新
- **← 所有子系统**：发布事件、用户反馈

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 平台数据 API 不全 | 多源补全 + 挂载项 A 爬虫 |
| 真实感公式经验值不准 | 持续校准 + 人工标注 ground truth |
| 归因引擎找出虚假相关 | 最小样本量阈值 + 双盲验证 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 基础数据回收（阅读/点赞/评论/收藏）
- ✅ 数据看板（手动产出洞察）
- ✅ 真实感公式（手动验证）

**MVP 不做**：
- ❌ 归因引擎（规模化阶段）
- ❌ 行动建议自动生成（规模化阶段）
- ❌ 爆款指纹库（规模化阶段）
