# ⑤ 账号与凭证管理

> 状态：📝 设计稿

## 职责（一句话）

管**账号档案**，不负责执行（执行是 ⑥ 的事）。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **档案/操作两层分离** | 档案层纯数据零风险，操作执行层可拔 |
| **账号性格档案** | 每个号有专属口头禅、emoji 偏好、句长习惯、配图风格 |
| **账号画像与匹配** | 粉丝画像、最佳发布时段、不同内容类型互动率 |
| **健康心跳监测** | 笔记存活率（24h 是否被隐藏）、真实评论率、功能受限标志 |
| **动态健康基线** | 阈值取同类账号 30 分位 |
| **熔断** | 健康分跌破阈值 → 强制 ASSIST + 停自动 |

---

## 关键设计决策

### 1. 档案 / 操作两层分离

```
┌────────────────────────────────────────────┐
│  档案层（纯数据，零风险）                       │
│  ├─ 账号基本信息（昵称、平台、粉丝数）           │
│  ├─ 性格档案（口头禅、emoji、风格）              │
│  ├─ 画像（粉丝标签、互动数据）                   │
│  └─ 健康指标（存活率、限流标记）                 │
└────────────────────────────────────────────┘
            ⫻（API 隔离）
┌────────────────────────────────────────────┐
│  操作执行层（可拔）                            │
│  └─ 由 ⑥ 调度，按 driver 实际发布              │
└────────────────────────────────────────────┘
```

**为什么**：档案是资产，永远不丢；操作随时可换 driver、可降级。

### 2. 账号性格档案

每个号有独立 prompt 补丁，例如：

```json
{
  "account_id": "xhs_account_007",
  "voice_persona": {
    "catchphrases": ["真的会谢", "建议人手一个"],
    "emoji_preference": ["🌟", "💧", "✨"],
    "sentence_length_avg": 12,
    "first_person_ratio": 0.7,
    "visual_style": "morandi_warm_tone"
  },
  "negative_words_from_review_diff": ["全网最低", "强烈推荐"],
  "topic_affinity": {
    "skincare": 0.9,
    "makeup": 0.6,
    "lifestyle": 0.3
  }
}
```

**为什么**：矩阵号同质化的根本解。一个号一个语气，AI 算法才不会判定为同号。

### 3. 健康心跳

每个号每天自动跑一遍体检：

| 指标 | 说明 | 警戒线 |
|---|---|---|
| 笔记存活率 | 发布后 24h 仍可见的比例 | < 80% → 黄牌 |
| 真实评论率 | 评论数 / 阅读量 | < 同类 30 分位 |
| 功能受限标志 | 禁言 / 限流 / 滑块 | 任一触发 → 红牌 |
| 粉丝异常波动 | 24h 内 ±10% | 触发即告警 |

### 4. 动态健康基线

阈值不写死，而是取**同类账号 30 分位**作为预警线。

**为什么**：平台规则随时变，写死的阈值会过时。动态基线自动跟随。

### 5. 熔断

健康分 < 阈值时：
- 自动切 ASSIST，禁用 AUTO driver
- 停止自动填充
- 仅允许真人手动发
- 通知风控总线

---

## 输入 / 输出

**输入**：账号注册信息 / 来自 ⑥ 的发布反馈 / 来自 ⑦ 的健康数据
**输出**：账号档案对象 / 健康熔断决策 → ⑥

---

## 与其他子系统的接口

- **→ ③**：性格档案注入到生成 prompt
- **→ ⑥**：可用账号清单 + 各账号当前 driver 模式
- **→ ⑦**：账号画像供归因分析
- **→ 风控总线**：健康事件推送
- **← 配置中心**：拉取健康阈值规则

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 凭证泄漏 | 凭证独立加密存储 + 与档案层物理隔离 |
| 性格档案被复制（多号撞声） | 档案哈希查重 + 主动多样化建议 |
| 健康数据误报（平台抽风） | 多日趋势判断而非单日触发 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 账号档案基本字段
- ✅ 账号性格档案（手工维护起步）
- ✅ 健康心跳（基础指标）

**MVP 不做**：
- ❌ 动态健康基线（要等数据积累）
- ❌ 自动熔断（先用人工决策）
- ❌ 凭证自动轮换
