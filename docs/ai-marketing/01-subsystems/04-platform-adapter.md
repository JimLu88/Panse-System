# ④ 多平台适配器

> 状态：📝 设计稿

## 职责（一句话）

统一内容模型 → **N 个平台原生形态**。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **平台人格词典** | 每个平台预设语气基调、禁用词、必加元素 |
| **首屏折叠线优化** | 根据各平台前端显示规则，强制把钩子压在折叠线以内 |
| **1→N→M 变体生成** | 每平台 2–3 个变体（不同钩子 / 开头 / 标签组合） |
| **本地化 Agent**（海外） | 中文流行语换成当地 TikTok/Reddit 同义平替，不是直译 |
| **反共振调度协作** | 同选题多账号分发时强制随机延迟 + 标签打散 |

---

## 平台人格词典示例

| 平台 | 语气基调 | 禁用词 | 必加元素 |
|---|---|---|---|
| 小红书 | 闺蜜聊天体 | 极限营销话术（如"全网最低价"等违禁词） | emoji、问句钩子、3:4 封面 |
| Instagram | 慵懒高级感 | 直接转化话术 | 故事化文案、Reels 时长 |
| Pinterest | 教程工具感 | 口语化感叹词 | 步骤编号 + 尺寸标注 |
| 知乎 | 理性分析体 | 营销话术 | 引用、数据、结构化标题 |
| 抖音 / TikTok | 节奏感强 | — | 前 3 秒钩子、字幕、BGM 提示 |
| 快手 | 接地气、生活流 | "高大上"、"精致" | 真实场景、方言可用 |
| 小黑盒 | 游戏圈黑话 | — | 游戏 ID、版本号、装备截图 |

## 关键设计决策

### 1. 1 个核心稿 → N 个平台版本 → 每平台 M 个变体

```
   核心叙事单元（hook/pain/solution/case/cta）
            │
            ├─→ 小红书版本 v1, v2, v3
            ├─→ Instagram 版本 v1, v2
            ├─→ Pinterest 版本 v1
            └─→ TikTok 版本 v1, v2
```

**为什么**：
- N 版本：平台调性不同
- M 变体：A/B 测试不同钩子，找最优解；反共振调度需要

### 2. 首屏折叠线优化

各平台的折叠规则不同：
- 小红书：标题 20 字 + 正文前 50 字
- Instagram：caption 前 125 字符
- 知乎：标题 + 摘要前 100 字

钩子必须压在折叠线之前。

### 3. 本地化 Agent（海外）

不是简单翻译。例如：

| 中文流行语 | TikTok 美国区平替 | Reddit 平替 |
|---|---|---|
| "绝绝子" | "no way fr" / "lit" | "this is gold" |
| "踩雷了" | "this is a flop" | "got burned" |
| "yyds" | "GOAT" | "the OG" |

### 4. 反共振调度协作

同一选题在多账号分发时：
- 强制错峰 23 / 47 分钟级别的随机延迟
- 标签 / 关键词交叉打散（不要 5 个号同时打同样 #）

详见 [06-dispatcher](06-dispatcher.md)。

---

## 输入 / 输出

**输入**：来自 ③.5 审核通过的稿件（核心叙事单元）
**输出**：每个目标平台的 N×M 个变体，写入分发队列

---

## 与其他子系统的接口

- **← ③.5**：接收通过稿
- **→ ⑥**：把适配后的变体入分发队列
- **← 配置中心**：拉取人格词典 / 折叠线规则 / 本地化映射
- **挂载项 B 图片指纹变形**：可选挂载，详见 [B-image-fingerprint](../04-mount-modules/B-image-fingerprint.md)

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 平台规则突变（折叠线变了） | 配置中心规则监听，72h 预警 |
| 本地化用力过猛（变成洋泾浜） | 本地化 Agent 训练时只学高赞当地内容 |
| 变体太多审核员审不过来 | 同一篇的变体合并审核，只看差异点 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 小红书 + 1 个对照平台（建议知乎 或 Pinterest）
- ✅ 人格词典
- ✅ 首屏折叠线优化

**MVP 不做**：
- ❌ 抖音 / TikTok / 快手 / Ins / 小黑盒（扩展阶段）
- ❌ 本地化 Agent（海外阶段）
- ❌ 挂载项 B 图片指纹变形
