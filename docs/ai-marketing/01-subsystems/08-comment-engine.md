# ⑧ 评论引流站

> 状态：📝 设计稿
> ⚠️ **铁律前置**：本子系统**永不全自动发评论**。全自动评论是小红书打击最狠的行为（封号近乎确定性），且与铁律 1「合规与账号安全 > 一切」直接冲突。系统只负责"找机会 + 写稿"，发出永远由人完成。

## 职责（一句话）

在垂类**上升期优质笔记**下进行"人在环内"的评论引流：系统发现机会 → AI 草拟评论 → 人工 3 秒审核点发。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **上升期笔记发现器** | 监控家居垂类发布 2–24h 内互动增速高的笔记（点赞/收藏增速 + 评论活跃度） |
| **关键词匹配产品线** | 笔记内容与自家产品线（餐桌/餐椅/柜类…）关键词匹配，匹配度打分 |
| **AI 评论草拟** | 按目标笔记语境 + 执行账号性格档案草拟评论，走 ③ 同款敏感词预检 |
| **话术分层** | 种水型（不提品牌："我家也是榉木的，确实耐造"）与引导型（"可以搜 XX 看看"）按比例混用 |
| **人工一键发** | 工作台推送机会卡片（笔记摘要 + 草稿 + 匹配理由），人工审核后复制/跳转发出 |
| **频控与反共振** | 单号每日评论上限、同笔记下多号互斥、评论任务并入 ⑥ 的反共振调度 |
| **效果回采** | 评论的回复/点赞、由评论带来的私信线索（→ ⑩ 登记来源） |

---

## 关键设计决策

### 1. 永不全自动（人在环内）

```
   发现器（自动） → 匹配打分（自动） → 草拟（AI） → 人工审核点发（必须真人）
```

**为什么**：自动评论的行为指纹（频率、间隔、文本模式）是平台风控重点训练目标；批量软广评论另有不正当竞争/广告合规风险。"系统找机会 + AI 写稿 + 人 3 秒点发"保留 ~90% 效率，把风险压到可控。

### 2. 话术分层（种水 : 引导 ≈ 7 : 3）

| 类型 | 示例 | 作用 |
|---|---|---|
| 种水型 | "我家也是榉木的，两年了没开裂" | 建立真实人设，不触发营销识别 |
| 引导型 | "之前对比过几家，可以搜 [暗号] 看看" | 实际引流，配 ⑩ 的归因暗号 |

**为什么**：纯广告式评论既被删也被骂；全种水又没有转化。比例可在配置中心热调。

### 3. 目标优选"装修日记类"笔记

家具是长决策品类。**装修进行中的用户（装修日记/求助帖）转化价值远高于泛家居爆款的吃瓜流量**。发现器给"装修日记 + 进行到家具环节"的笔记额外加权。

### 4. 评论额度并入反共振调度

- 单号每日评论上限（初始 ⚠️ 5 条/天，待数据校准）
- 同一目标笔记下，矩阵内最多 1 个号出现
- 评论时间随机抖动，不与发布任务同分钟扎堆

**为什么**：评论和发布共享账号行为画像，分开调度会互相打架触发风控。

### 5. 评论也走合规预检

草稿过 ③ 的敏感词分级（S 级拒绝 / A 级强制人工改 / B 级预警）+ 家具违禁词库（零甲醛/纯天然/最/第一）。

---

## 输入 / 输出

**输入**：
- 垂类笔记流（来自 ① 热点雷达共用的采集源 / 挂载项 A）
- 产品线关键词库（来自配置中心，源头是 Panse-System ERP 产品表）
- 执行账号性格档案（来自 ⑤）

**输出**：
- 机会卡片（笔记摘要 + 匹配分 + 评论草稿 + 推荐执行号）→ 工作台
- 评论发出事件 + 效果数据 → ⑦
- 引流线索 → ⑩ 线索收件箱（标记来源=评论引流）

---

## 与其他子系统的接口

- **← ①/挂载项 A**：共用采集源，垂类笔记流
- **← ⑤**：执行账号档案 + 健康状态（红牌号自动跳过）
- **→ ⑥**：评论任务并入反共振调度（assist 形态）
- **→ ⑦**：评论效果数据入分析管道
- **→ ⑩**：评论带来的私信线索登记
- **→ 风控总线**：评论被删 / 被举报 / 触发验证码 → 立即暂停该号评论任务

---

## 风险点 & 缓解

| 风险 | 缓解 |
|---|---|
| 账号被封（最高风险） | 人在环内 + 每日频控 + 健康红牌跳过 + 风控总线熔断 |
| 被识别为营销号（评论被折叠/删除） | 话术分层 7:3 + 性格档案注入 + 不重复文本模式 |
| 评论被删率升高（信号） | 删除率 > 20% → 自动暂停该号 48h + 推送人工复盘 |
| 合规（广告法/不正当竞争） | 引导型话术不贬低竞品、不绝对化用词、走敏感词预检 |

---

## MVP 里做什么、不做什么

**MVP 做**：
- ✅ 上升期发现器（规则版：互动增速阈值）
- ✅ 关键词匹配 + 机会卡片工作台
- ✅ AI 草拟 + 敏感词预检
- ✅ 全人工发出 + 手工登记效果

**MVP 不做**：
- ❌ 任何形式的自动发出
- ❌ 评论效果自动回采（先手工）
- ❌ 装修日记加权模型（先规则）
