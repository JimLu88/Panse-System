## 国内平台

### 小红书 (xhs)

| 维度 | 信息 |
|---|---|
| 内容形式 | 图文笔记 + 短视频 |
| 首屏折叠线 | 标题 20 字 + 正文前 50 字 ⚠️ 待精确 |
| 推荐标签数 | 5–10 |
| 封面比例 | 3:4 |
| 官方 API | 仅企业账号有限开放 |
| 默认 driver | ASSIST |
| 关键风险 | 营销话术、第三方平台名、违禁品 |
| 平台规范来源 | 小红书社区规则 + 创作者公约 |

### 知乎 (zhihu)

| 维度 | 信息 |
|---|---|
| 内容形式 | 文章 / 回答 / 想法 |
| 首屏折叠线 | 标题 + 摘要前 100 字 ⚠️ 待精确 |
| 调性 | 理性分析 / 引用数据 |
| 官方 API | 基本无 |
| 默认 driver | ASSIST |
| 关键风险 | 营销话术、低质量答案被折叠 |

### 抖音 (dy)

| 维度 | 信息 |
|---|---|
| 内容形式 | 短视频为主 |
| 视频要求 | 9:16，1–3 分钟，前 3 秒钩子 |
| 推荐标签数 | 3–5 |
| 官方 API | 部分企业接入 |
| 默认 driver | ASSIST |
| 关键风险 | 内容低质、营销隐性引导 |

### 快手 (ks)

| 维度 | 信息 |
|---|---|
| 内容形式 | 短视频 + 图文 |
| 调性 | 接地气、生活流 |
| 推荐标签数 | 3–5 |
| 官方 API | 有限 |
| 默认 driver | ASSIST |
| 关键风险 | 与抖音类似 |

### 小黑盒 (xhh)

| 维度 | 信息 |
|---|---|
| 内容形式 | 游戏圈帖子 / 攻略 / 评测 |
| 调性 | 游戏圈黑话 |
| 必加元素 | 游戏 ID / 版本号 / 装备截图 |
| 官方 API | ⚠️ 待调研 |
| 默认 driver | ASSIST |

## 海外平台

### Instagram (ins)

| 维度 | 信息 |
|---|---|
| 内容形式 | Feed 帖 / Reels / Stories |
| Caption | 前 125 字符为首屏 |
| 调性 | 慵懒高级感 |
| 官方 API | Graph API（需 Business + App Review）|
| 推荐 driver | API |
| 关键限制 | 单次最多 10 张图，Reels 最长 90 秒 ⚠️ 待精确 |

### TikTok (tt)

| 维度 | 信息 |
|---|---|
| 内容形式 | 短视频 |
| 视频要求 | 9:16，最长 10 分钟 ⚠️ 待精确，前 3 秒抓人 |
| 调性 | 节奏感强 |
| 官方 API | Content Posting API（需审批）|
| 推荐 driver | API |

### Pinterest

| 维度 | 信息 |
|---|---|
| 内容形式 | Pin (图文) / Idea Pin |
| 调性 | 教程工具感 |
| 必加元素 | 步骤编号 + 尺寸标注 |
| 官方 API | Developer API（需 App Approval）|
| 推荐 driver | API |

### YouTube

| 维度 | 信息 |
|---|---|
| 内容形式 | 长视频 / Shorts |
| 官方 API | Data API（OAuth）|
| 推荐 driver | API |

### X (Twitter)

| 维度 | 信息 |
|---|---|
| 内容形式 | 推文 / 图片 / 短视频 |
| 字数限制 | 280 字符 |
| 官方 API | Developer Portal 付费档 |
| 推荐 driver | API |

### Facebook Pages

| 维度 | 信息 |
|---|---|
| 与 Instagram | 同账号体系（Meta）|
| 官方 API | Graph API |
| 推荐 driver | API |
