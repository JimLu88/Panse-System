# 挂载项 B · 图片指纹变形流水线

> 状态：📝 设计稿 / **默认关闭**

## 概述

裁剪 / 亮度 / 噪点 / 水印等图片处理流水线，让"同一张图"在不同账号上看起来"不是同一张"。

> ⚠️ **伦理争议**：同质化批量号会用，所以做成开关——配置中心设"原创伦理等级"。

---

## 默认状态

❌ **关闭**

---

## 启用前提

仅在 **"素材二创"伦理等级**下开启：

| 伦理等级 | 行为 |
|---|---|
| **高原创**（默认） | 只允许调尺寸（裁剪至平台比例），不允许变形 |
| **中原创** | 允许轻微亮度 / 对比度调整 |
| **素材二创** | 允许全流水线（裁剪 / 亮度 / 噪点 / 水印） |

**默认关闭，不勾就不会无意触发**。

---

## 依赖的其他挂载项

无。独立。

---

## 流水线能力

| 操作 | 用途 |
|---|---|
| 智能裁剪 | 适配 3:4 / 1:1 / 9:16 等平台比例 |
| 亮度 / 对比度微调 | 改变图片指纹 |
| 局部噪点注入 | 改变图片指纹 |
| 水印 / 角标添加 | 账号品牌一致性 |
| 元数据洗白 | 移除拍摄设备 / GPS 等 EXIF |

---

## 与子系统的关系

```
   ③ 生成 → 原图
        ↓
   ④ 适配器
        ↓
   挂载项 B（仅在伦理等级允许时）
        ↓
   不同账号 → 不同变形版本 → 分发
```

---

## 维护成本评估

**低**：
- 纯本地处理，无外部依赖
- 算法成熟（OpenCV / PIL 即可）
- 平台不会针对单一图片指纹来封号

但：
- **声誉成本可能高**：一旦被舆论标记为"批量号工具"，对正版用户的吸引力下降

---

## 商业 ROI 判断点

需要看：
- 矩阵号是否真的需要"图片差异化"？（原创账号不需要）
- 用户群体是哪类？（白帽用户基本不会用）
- 启用后能否定量提升账号存活率？

**只在数据证明 ROI 正向后才挂**。

---

## 风险点

| 风险 | 缓解 |
|---|---|
| 被识别为批量号工具，伤品牌 | 默认关闭 + 用户主动开启 |
| 处理后图片质量下降 | 质量阈值 + 人工审核 |
| 用户误开启 | 配置中心二次确认 + 警示文案 |

---
