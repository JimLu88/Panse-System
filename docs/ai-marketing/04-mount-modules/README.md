# 挂载项总览（"用不用再说"的部分）

> 状态：📝 设计稿

下面这些**全部做成可插拔模块**，默认关闭或独立部署，架构上预留接口。要不要启用、什么时候启用，**后面再决策**。

## 依赖关系图

```
   A (本地爬虫)     ← 独立，可单独启用
        ↓
        ② 采集分析

   I (血缘追踪)     ← 独立，推荐启用
        ↓
        ②③④（贯穿）

   B (图片指纹变形) ← 独立，仅"素材二创"伦理等级开启
        ↓
        ④ 适配器

   H (合规水印)     ← 独立，商业化阶段挂
        ↓
        ③ + ④

   C (海外 API)     ─┐
   D (国内自动)     ─┤
                    ├─→ 需要 E（代理环境）
   E (环境胶囊)     ─┤
                    └─→ 启用 D 时强烈建议挂 F（指纹浏览器）
   F (指纹浏览器)

   G (批量注册)     ← 风险最高 / 单独评估，依赖 E + F
```

**关键依赖校验**（配置中心必须实施）：
- D 关闭时，E 和 F 都没意义，配置中心提示
- G 启用必须同时启用 E + F + 风控总线告警
- 启用 C/D 但不启用 E → 配置中心强警告

## 通用启用清单

挂任何一项前，必须确认：

- [ ] 这一项带来的商业价值能覆盖风险？
- [ ] 风控总线已经准备好处理它产生的事件？
- [ ] 出问题时能 5 分钟内拔掉它（disable）？
- [ ] 它的事件 / 日志已经纳入观测体系？
- [ ] 在国内 vs 海外实例上的启用策略是否一致？

任何一项 ❌ → **不挂**。
