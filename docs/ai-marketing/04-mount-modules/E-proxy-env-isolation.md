# 挂载项 E · 代理与环境隔离层（"环境胶囊"）

> 状态：📝 设计稿 / **默认关闭**

## 概述

为每个账号提供独立的**网络 + 设备指纹 + 行为环境**容器。

避免"同 IP / 同设备 = 同号"被识别。

---

## 默认状态

❌ **关闭**

---

## 启用前提

- 启用挂载项 C（海外 API）→ 强烈建议
- 启用挂载项 D（国内自动）→ 必须

---

## 依赖的其他挂载项

- 通常与 F（指纹浏览器）配套
- 服务于 C 和 D

---

## 环境胶囊组成

每个账号一个"环境胶囊"：

```
账号 A 胶囊：
├─ 代理 IP（独立 / 长期持有 / 同城）
├─ User-Agent + 浏览器指纹（独立）
├─ Cookie + LocalStorage（独立）
├─ 时区 + 语言（与代理 IP 一致）
├─ 屏幕分辨率 + GPU 指纹（独立）
└─ 行为档案（独立）
```

---

## 关键设计决策

### 1. 一号一胶囊（持久）

每个账号长期绑定同一个胶囊。
- **不要**今天 IP A 明天 IP B（会被识别为多账号迁移）
- **不要**多账号共用一个胶囊（会被关联）

### 2. 地理一致性

代理 IP 地区 = 账号注册地区 = 时区设置 = 语言设置
- 不一致 → 风控立即标记

### 3. 持续可用性

代理 IP 不能挂，否则账号"突然消失"：
- 双备份 IP 池
- 自动切换前先 30 秒预热
- 切换记录到风控总线（频繁切换 = 异常）

### 4. 与挂载项 F 的关系

E 提供网络层 + 基础环境；F 提供应用层（浏览器指纹）：
- E 只挂 → 基础隔离（够用于 API 模式）
- E + F → 完整隔离（自动操作需要）

---

## 代理类型选型

| 类型 | 适用 | 成本 | 风险 |
|---|---|---|---|
| 数据中心代理 | 不推荐（容易被识别） | 低 | 高 |
| 住宅代理 | 推荐 | 中 | 低 |
| 移动代理 | 高端方案 | 高 | 最低 |
| 自建代理 | 海外 VPS | 中 | 中 |

---

## 与子系统的关系

```
   ⑥ 调度 → 选 driver
        ↓
   driver 发起请求
        ↓
   挂载项 E（环境胶囊层）
        ↓
   代理 / UA / Cookie / 指纹注入
        ↓
   平台
```

胶囊层对 driver 透明。Driver 只负责"发什么"，胶囊负责"怎么发"。

---

## 维护成本评估

**中**：
- 代理服务持续付费（每号每月 $5–20）
- 胶囊配置文件维护
- IP 健康度监控

---

## 商业 ROI 判断点

启用 C / D 时 ROI 是**正向且确定**的——账号存活率显著提升。

不启用 C / D 时，启用 E 没意义。

---

## 风险点

| 风险 | 缓解 |
|---|---|
| 代理 IP 被平台拉黑 | 多备份 + 健康监控 |
| 胶囊配置错误（不一致） | 启动前自检脚本 |
| 代理服务商泄漏数据 | 信誉评估 + 重要号自建 |
| 多个号共用 IP 段被关联 | 严格一号一 IP，且分散 IP 段 |
