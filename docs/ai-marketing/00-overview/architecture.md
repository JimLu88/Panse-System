## 信息流向

1. **正向（生产链）**：① 出选题 → ② 采集学习 → ③ 生成草稿 → ③.5 人工审核 → ④ 适配多平台 → ⑥ 调度发布
2. **反向（数据回流）**：⑦ 回收数据 → 反哺 ① 选题决策 + 更新 ② 风格库 + 优化 ③ Prompt
3. **横向（支撑）**：横向三层为所有子系统提供配置 / 风控 / LLM 服务

## 部署形态（物理隔离）

```
┌─ 内容核心层（共享代码库） ───────────────────┐
│  ①②③④ 子系统的纯逻辑部分                    │
│  统一内容模型、Prompt 资产、风格 DNA 库       │
└──────────────────────────────────────────┘
         ↓ 部署为两套独立实例 ↓
┌─ 国内业务实例 ──────┐    ┌─ 海外业务实例 ──────┐
│  ⑤⑥⑦ 国内运营       │    │  ⑤⑥⑦ 海外运营       │
│  默认 ASSIST 模式    │    │  默认 AUTO 模式      │
│  国内服务器/数据库    │    │  境外节点/独立数据库  │
│  挂载 D/E/F/G 按需   │    │  挂载 C/E 按需       │
└─────────────────────┘    └─────────────────────┘
```
