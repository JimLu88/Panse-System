按主题分类排列，便于检索。

## 模式与角色

| 术语 | 含义 |
|---|---|
| **ASSIST 模式** | 半自动模式：系统生成内容 + 提醒 + 半自动填充剪贴板，人工最后一步发布 |
| **AUTO 模式** | 自动模式：通过官方 API 或自动化驱动直接发布 |
| **driver** | 分发执行的具体实现（api_driver / assist_driver / automation_driver） |
| **挂载项 A~I** | 可插拔的高阶能力模块，默认关闭。详见 [04-mount-modules](../04-mount-modules/README.md) |

---

## 数据与内容

| 术语 | 含义 |
|---|---|
| **统一内容模型** | 全系统对话的语言，基于事件流（Event Sourcing）+ 结构化叙事单元 |
| **叙事单元（Narrative Unit）** | 原子化内容片段（hook / pain_point / solution / case / cta），可重组成不同平台版本 |
| **风格 DNA** | 强制 JSON 化的写作风格特征（句长 / emoji 频率 / 钩子类型 / 结构模式 ...） |
| **风格 DNA 库** | 风格 DNA 的向量化集合，可秒级调取与匹配 |
| **3 要素脱敏** | 品牌名 / 人名 / 具体型号统一替换为泛化标签（如 `[口红品牌][色号]`） |
| **血缘字段（lineage）** | 每条内容记录的参考来源 / prompt 版本 / 风格模板 ID，用于同质化检测 |
| **内容指纹** | 内容的可比对特征向量，用于溯源、查重、爆款入库 |

## 生产流水线

| 术语 | 含义 |
|---|---|
| **四层流水线** | ③ 生成引擎的核心结构：逻辑重构 → 事实核查 → 风格注入 → 合规预检 |
| **必改 3 节点** | 首图文字覆盖率 / 第二段营销话术 / 个人化细节密度，三处永远高亮，审核员 5 秒确认 |
| **平台人格词典** | 每个平台预设的语气基调 / 禁用词 / 必加元素 |
| **1→N→M 变体** | 1 个核心稿 → N 个平台版本 → 每平台 M 个变体（不同钩子/开头/标签） |
| **本地化 Agent**（海外） | 中文流行语换成当地 TikTok/Reddit 同义平替，不是直译 |
| **视觉一致性锚定** | 生图不直出图片，而是产出 ComfyUI/Flux 工作流参数（固定 Seed/Lora/排版标签） |
| **首屏折叠线** | 各平台前端显示规则下，必须把钩子压在折叠线以内 |

## 账号与分发

| 术语 | 含义 |
|---|---|
| **账号性格档案** | 每个号的专属口头禅 / emoji 偏好 / 句长习惯 / 配图风格，注入生成 prompt |
| **健康心跳** | 笔记存活率（24h 是否被隐藏） / 真实评论率 / 功能受限标志 |
| **动态健康基线** | 阈值不固定，取同类账号 30 分位作为预警线 |
| **沙盒预发** | 正式发布前在观察号或测试环境跑一遍 |
| **反共振算法** | 同选题多账号强制错峰 + 标签交叉打散 |
| **环境胶囊** | 代理 + 浏览器指纹 + 设备特征的隔离容器 |
| **熔断** | 健康分跌破阈值时强制降级到 ASSIST 或停号 |

## 数据回收

| 术语 | 含义 |
|---|---|
| **真实感** | `0.4×提问评论率 + 0.3×用户间互动率 + 0.3×长评论占比`，<0.6 推送人工复盘 |
| **冷启动加权** | 新号 0.2 / 千粉号 1.0 / 万粉号 2.5 |
| **归因引擎** | 分析组合效果（"油痘肌 + 自救日记 + 3:4 封面"），而非单因素 |
| **爆款指纹库** | 质量分超阈值的内容自动入库，特征反哺 ① |
| **内容指纹溯源** | 发布后 24h 监控同赛道竞品内容，识别选题被压制 |

## 横向支撑

| 术语 | 含义 |
|---|---|
| **风控事件总线** | 所有子系统异常信号汇聚到一条总线，由独立风控决策模块订阅 |
| **配置规则中心** | 集中管理易变项（敏感词 / 平台规则 / 模板），支持热更新与灰度 |
| **敏感词分级** | S 级自动熔断 / A 级强制人工确认 / B 级仅预警 |
| **规则沙盒灰度** | 新一批规则先 5% 低权重测试账号灰度，确认无误再全量 |
| **多 LLM 路由** | 顶级模型（Claude/GPT-4o）+ 廉价模型（DeepSeek/GPT-4o-mini）按任务分层调用 |
