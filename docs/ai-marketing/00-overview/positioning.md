# 定位与设计哲学

> 状态：📝 设计稿

## 一句话定位

**AI 驱动的内容生产流水线 + 多模式可插拔分发引擎。**

服务于小红书、知乎、抖音、快手、Instagram、TikTok、小黑盒等多平台内容矩阵的自动化生产 + 半自动 / 自动分发。

---

## 三条核心设计原则（贯穿整个系统）

### 1. 生产与对抗解耦

内容生产（选题 → 生成 → 适配）和分发执行（账号 → 调度 → 发布）**完全分离**。

- 前者零风险、高价值，先做
- 后者按需挂载

> **意义**：即使分发侧因平台对抗变化全盘失效，生产侧的资产（prompt、风格 DNA、模板）仍然完好且可用。

### 2. 默认半自动，对抗能力可插拔

- **海外**走官方 API
- **国内**走 ASSIST 模式（生成 + 提醒 + 半自动填充）作为默认形态
- 自动化操作、代理隔离、风控对抗 → 全部做成"挂载模块"，开关在配置中心

> **意义**：主架构永远干净，对抗能力可拔可插，业务不被风控对抗拖累。

### 3. 数据驱动，越用越聪明

所有 prompt、模板、风格、规则都是**版本化资产**：

- 能 A/B 测试
- 能回滚
- 能反哺到选题与生成

> **意义**：这是真正的壁垒——不是某个功能，而是数据闭环。

## 与同类工具的差异

| 维度 | 通用 AIGC 工具 | 本系统 |
|---|---|---|
| 输出形态 | 单篇内容 | 矩阵号内容流 + 版本化资产 |
| 风险态度 | 不关心 | 生产/分发解耦、挂载项默认关闭 |
| 平台适配 | 一稿多发 | 平台人格词典 + 1→N→M 变体 |
| 数据闭环 | 一次性 | 真实感归因 + 反哺选题 |
| 同质化 | 不解决 | 账号性格档案 + 反共振调度 |
