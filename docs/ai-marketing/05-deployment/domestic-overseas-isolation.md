# 部署形态：国内 / 海外物理隔离

> 状态：📝 设计稿
> ⚠️ **战略级决策，越早分越好**。

---

## 概述

```
┌─ 内容核心层（共享代码库） ───────────────────┐
│  ①②③④ 子系统的纯逻辑部分                    │
│  统一内容模型、Prompt 资产、风格 DNA 库       │
└──────────────────────────────────────────┘
         ↓ 部署为两套独立实例 ↓
┌─ 国内业务实例 ──────┐    ┌─ 海外业务实例 ──────┐
│  ⑤⑥⑦ 国内运营       │    │  ⑤⑥⑦ 海外运营       │
│  默认 ASSIST 模式    │    │  默认 AUTO 模式      │
│  国内服务器/数据库    │    │  境外节点/独立数据库  │
│  挂载 D/E/F/G 按需   │    │  挂载 C/E 按需       │
└─────────────────────┘    └─────────────────────┘
```

---

## 为什么物理隔离

### 1. 合规要求不同

| 维度 | 国内 | 海外 |
|---|---|---|
| 数据出境 | 受《数据出境安全评估办法》约束 | 无 |
| 内容审查 | 严格 | 宽松 |
| AI 生成标识 | 暂行办法要求 | 部分国家要求 |
| 个人信息保护 | PIPL | GDPR / CCPA |

### 2. 风控策略不同

- 国内 → 默认 ASSIST，避免任何对抗
- 海外 → 默认 AUTO（官方 API），效率优先

### 3. 出事不相互连累

如果国内业务被监管处罚，不影响海外业务运营。反之亦然。

### 4. 网络拓扑不同

- 国内：境内数据中心 → 国内平台
- 海外：境外节点 → 海外平台
- 跨境流量延迟、被墙、被检测 = 雷区

## 共享 vs 独立

### 共享部分（内容核心层）

**代码层面共享**，但**运行实例独立**：

- 子系统 ①②③④ 的实现代码
- 统一内容模型 / 叙事单元 / schema
- Prompt 模板库 / 风格 DNA 库

形式：
- 一个 Git 仓库
- 通过 CI/CD 部署到两套实例
- 配置中心负责差异化（国内禁用某些功能 / 海外启用某些挂载项）

### 独立部分（业务运行层）

- 数据库 / 缓存 / 消息队列：完全独立
- 账号 / 凭证 / Cookie：完全独立
- 数据回收 / 分析：完全独立（数据不可跨境互通）
- 挂载项启用：按实例独立配置

## 数据隔离规则

| 数据类型 | 国内实例 | 海外实例 | 跨境流向 |
|---|---|---|---|
| 风格 DNA 库 | ✅ | ✅ | 可以单向同步（脱敏后）|
| Prompt 模板 | ✅ | ✅ | 可以双向同步（不含具体内容）|
| 账号档案 / 凭证 | ✅ | ✅ | **绝不跨境** |
| 内容数据（含 metrics） | ✅ | ✅ | **绝不跨境** |
| 真实感归因 | ✅ | ✅ | 各自独立 |

## 关键设计决策

### 1. 一开始就分

**不要**先做一套通用的然后再"国内化 + 海外化"。

**应该**：MVP 阶段只做国内 / 只做海外其中一套，跑通后用同代码部署另一套。

### 2. 配置中心承担差异化

差异不写死在代码里，全部走配置：

```yaml
# 国内实例 config
default_driver: assist
enabled_mounts: [A, I]
forbidden_words_pack: domestic
fold_line_rules: domestic.xhs

# 海外实例 config
default_driver: api
enabled_mounts: [A, I, C, E]
forbidden_words_pack: overseas
fold_line_rules: overseas.ins
```

### 3. 不要尝试跨境账号

- 国内号在海外 IP 登录 → 风控立即标记
- 海外号在国内 IP 登录 → 同样

### 4. 监控独立

每套实例独立的：
- 错误告警
- 指标仪表盘
- 风控事件总线

## 与挂载项的关系

| 挂载项 | 国内实例 | 海外实例 |
|---|---|---|
| A 本地爬虫 | ✅ | ✅（境外爬虫独立部署）|
| B 图片指纹变形 | 慎用 | 慎用 |
| C 海外 API | ❌ | ✅ 推荐 |
| D 国内自动操作 | ⚠️ 评估 | ❌ |
| E 代理环境 | 启用 D 时配套 | 启用 C 时配套 |
| F 指纹浏览器 | 启用 D 时配套 | 通常不需要 |
| G 批量注册 | ❌ 默认 | ❌ 默认 |
| H 合规水印 | 商业化阶段 | 商业化阶段 |
| I 血缘追踪 | ✅ 推荐 | ✅ 推荐 |

## 风险点

| 风险 | 缓解 |
|---|---|
| 配置错误把国内数据写到海外 | 配置中心硬约束 + 测试网络隔离 |
| 共享代码层引入跨境依赖 | 代码审计 / lint 规则 |
| 双实例运维成本翻倍 | IaC + 自动化运维 |
