> 状态：📝 设计稿

## 目标

---

## 验收标准

- [ ] 4 平台共 30+ 真实账号，每周累计发布 ≥ 200 篇
- [ ] Instagram + Pinterest 至少有一个跑 AUTO 模式
- [ ] ASSIST 沉浸式工作台单篇耗时 ≤ 30 秒（实测）
- [ ] 反共振调度避免至少 1 起"矩阵被识别"
- [ ] 国内 / 海外实例分别独立部署 + 监控
- [ ] 风控事件总线累计接收 ≥ 1000 个事件，决策模块产生 ≥ 100 个决策
- [ ] 沙盒预发拦截 ≥ 5 起"差点出事"的发布

---

## 关键风险

| 风险 | 缓解 |
|---|---|
| 海外 API 申请被拒 | 备用方案 ASSIST + 多平台并行申请 |
| 代理 IP 频繁挂 | 双备份 IP 池 + 健康监控 |
| 国内 / 海外双实例运维成本翻倍 | IaC + 自动化运维 + 共享代码层 |
| 反共振参数调不好 | A/B 测试 + 实时数据观察 |
