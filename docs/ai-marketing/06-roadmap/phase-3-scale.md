# Phase 3 · 规模化阶段（7–9 月）

> 状态：📝 设计稿

## 目标

**智能化与商业化**。

- 风格 DNA 库向量化
- 事实核查 + 视觉锚定
- 真实感归因 + 归因引擎
- Prompt / 模板 / 风格全面版本化 + A/B 测试

---

## 做的事

### 子系统升级

| 子系统 | Phase 3 增量 |
|---|---|
| ② 采集 | **风格 DNA 库 + 向量化**，风格资产秒级调取 |
| ③ 生成 | **事实核查完整版**（搜索 API + 企业知识库）；**视觉锚定（ComfyUI 工作流）** |
| ⑦ 数据回收 | **真实感归因**（完整公式）+ **归因引擎**（组合特征）+ **行动建议自动生成** |
| ① 选题 | **内容指纹溯源反哺**（24h 监控同赛道）|

### 横向支撑

- Prompt / 模板 / 风格全面版本化（git-like）
- A/B 测试基础设施
- LLM 路由质量回退完整版

### 挂载项

| 挂载项 | Phase 3 增量 |
|---|---|
| 现有 (A, C, E, I) | ✅ 持续完善 |
| F 指纹浏览器 | ⚠️ **评估启用** |
| 其他 | ❌ 不做 |

### 平台扩展

- 抖音 / 快手 / TikTok（短视频维度）
- 小黑盒（垂类）

视频类内容的"叙事单元"模型重新设计（脚本 + 分镜 + BGM）。

---

## 不做

- ❌ 国内自动操作（挂载项 D）— 仍在评估
- ❌ 批量注册（挂载项 G）
- ❌ 图片指纹变形（挂载项 B）
- ❌ 商业化版本（H 水印）

---

## 验收标准

- [ ] 风格 DNA 库 ≥ 500 个样本，向量检索 <100ms
- [ ] 至少 80% 的事实声明能被自动核查
- [ ] 视觉锚定让矩阵号同模板内容看起来"既统一又不同号"
- [ ] 归因引擎自动产出每周行动建议
- [ ] 真实感公式校准到与人工评估 ≥ 0.8 相关
- [ ] Prompt A/B 测试至少跑 10 组，得出胜出模板
- [ ] 视频平台至少 1 个跑通完整流程

---

## 关键风险

| 风险 | 缓解 |
|---|---|
| 视频内容生产成本高 | 先 PoC，确认 ROI 再规模化 |
| 向量检索数据量爆炸 | 按品类分库 + 老数据归档 |
| 事实核查成本不可控 | 缓存 + 仅核查关键声明 |
| A/B 测试样本不足 | 多账号并行 + 长周期测试 |

---

- 行动建议自动报告
- 视频内容生产能力
- Prompt 资产库（带 A/B 数据）
