# 床定制外尺寸页面

入口：原「定制报价」页面的「改现有产品」。不再设单独的床入口。输入产品编码/搜索床款名称，或描述识别命中原床款后，第三步自动显示床的尺寸与配置；不自动把床垫规格带成床体外尺寸。只进行测算及报价记录，不写商品、材料、活动或订单。

1. 选择产品和精确原款SKU，查看主材、铺板、原款大促到手价。
2. 查看原款外尺寸及其来源/确认状态；目标外长和外宽支持cm/mm切换，不采用床垫宽作为外长。
3. 去实木平板床头时单独输入已确认的实际板宽、板高和木料；不能将床体外宽自动当作板宽，不同床款尺寸资料可能有不同轴向。缺板宽不提交，cm/mm切换同步换算。软包、编织床隐藏平板扣价选项，只允许按自身BOM中的独立配件扣除；无独立成本时须补证据。异形床头不能视为同材质平板。
4. 原BOM配件按整套数量扣减；整套两盏灯仍为1套，不重复扣。支持增加物料库中的已知配置，板件尺寸以cm填写；未知或缺价不报价。
5. 每次更改输入都清除旧结果及确认。确认本次材质、铺板、大促到手价与外尺寸后计算。

结果为木作面积估算，不是工厂板单核价；支撑/脚/龙骨未核实，铺板采购价按原款整套保留。原款费用继承而非另加；不展示旧辅助成本估计为真实工厂成本。

接口：GET /api/customization/v2/bed-references 只读全床产品目录（含暂无真实SKU的床）及精确SKU/BOM；POST quote-light 使用 outer_dimensions + big_buyer。手工搜索无需AI；原描述识别仅辅助匹配，床的计算不走 quote-both，识别后仍需当次确认。目录加载失败不落回通用公式。保留非床旧路径。

2026-10-24全库只读验证：10款94真实SKU，8款80SKU可提供原款数据，240次原尺寸/缩小/放大测算以及270次增减已知板件/自身配件无计算错误，原价锚点、固定费用和四类价格表指纹保持一致。榉木编织床8SKU、主卧款6SKU缺原款外尺寸，阻断而不猜。该验证是现有数据下的估算一致性，不表示工厂结构、床脚和龙骨已核实。证据：outputs/bed-quote-unified-20261024。

关系审查：后端两个文件属于price.custom_reference；前端两文件当前关系图未建模，实际调用链已人工审查，不以未建模声称无影响。只锁定本次审核的来源，不重锁其他业务的旧来源。
