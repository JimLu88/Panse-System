# 床定制外尺寸页面

入口：顶部「定制报价」→「床定制（外尺寸）」。只进行测算及报价记录，不写商品、材料、活动或订单。

1. 选择产品和精确原款SKU，查看主材、铺板、原款大促到手价。
2. 查看原款外尺寸及其来源/确认状态；目标外长和外宽支持cm/mm切换，不采用床垫宽作为外长。
3. 去床头时输入已确认的实际板高和木料；宽度按目标外宽。软包/异形床头不能视为同材质平板。
4. 原BOM配件按整套数量扣减；整套两盏灯仍为1套，不重复扣。支持增加物料库中的已知配置，板件尺寸以cm填写；未知或缺价不报价。
5. 每次更改输入都清除旧结果及确认。确认本次材质、铺板、大促到手价与外尺寸后计算。

结果为木作面积估算，不是工厂板单核价；支撑/脚/龙骨未核实，铺板采购价按原款整套保留。原款费用继承而非另加；不展示旧辅助成本估计为真实工厂成本。

接口：GET /api/customization/v2/bed-references 只读精确SKU/BOM；POST quote-light 使用 outer_dimensions + big_buyer，不走 quote-both 或AI分类。保留非床旧路径。

关系审查：后端两个文件属于price.custom_reference；前端两文件当前关系图未建模，实际调用链已人工审查，不以未建模声称无影响。只锁定本次审核的来源，不重锁其他业务的旧来源。

验证：backend/tests/test_custom_quote_reference.py；frontend/e2e/bed_quote_form.py（明确模拟API，不替代生产页面验收）。生产页面、版本、价格表零写入与正式发布回执另外记录于outputs/custom-bed-quote-ui-20261024。
