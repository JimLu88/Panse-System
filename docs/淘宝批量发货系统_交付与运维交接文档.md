- **实际网络请求地址**：`https://wuliu2.taobao.com/gei/import/offline_consign_batch_upload.do`（`POST`）

- **修复实现**：在 [`scripts/fulfillment_batch_runner.py`](file:///D:/AI/畔色ERP系统/工作树/ERP-fulfillment-20261118/scripts/fulfillment_batch_runner.py) 的 `upload_and_submit` 中修正为：
  ```python
  async with self.page.expect_response(
      lambda r: ("offline_consign_batch_upload" in r.url or "consign2_batch_offline_consign" in r.url) and r.request.method == "POST",
      timeout=30000
  ) as resp_info:
      await ok_btn.first.click()
  ```
