## 字段与身份

- 材质及说明 → material_name；价格 → amount/total_amount（原表整行价格）。
- 尺寸（mm）/尺寸(mm) → spec，保留多行尺寸，不拆分价格或猜每块单价。
- 姓名、加工及原备注带标签保存在 remark。姓名不是供应商，不按姓名猜平台订单。
- 日期沿用已有 Excel 序列日期解析。不根据文件名强制将所有行归到六月。
- 缺少供应商保持空值。没有数量列时沿用原导入器的一条记录数量1口径，不将此解释为实物块数。
- 含姓名、加工或材质及说明表头的表采用 `客户明细表导入` 类型。防重键含日期、供应商、名称、整行金额、规格、数量、备注；逐次消耗导入前快照中的同内容记录。
- 不同客户不合并，同一文件完全相同的多行也保留其出现次数。原样重传（含改名/调序）不新增；增加同内容一行时只补一行。
- 普通采购表保留原非空更新规则。不会根据旧粗粒度键覆盖客户明细，也不会把客户明细覆盖到旧账。
- 无采购明细唯一号的文件：变更金额/姓名/加工后不能证明是旧行修改，按新内容处理。跨格式迁移、历史粗键记录与并发上传仍需另行核对，不宣称全场景幂等。
