# 工厂转发登记实施计划

ERP 是状态唯一来源；飞书群卡片和现有工厂表展示同一记录。

1. 按子订单记录待转发、已转发、暂缓转发，保留操作者、时间、版本和历史；旧母单兼容独立身份。
2. 新推图后回复操作卡；未知发送结果不重发图片或卡片。旧图不批量刷群。
3. ERP 工厂制作单提供状态修改、历史、筛选；飞书群支持状态查询。
4. 工厂多维表新增状态/操作人/时间列，沿用既有投影同步；失败保留待同步状态并有界重试。
5. 完成 10 个随机种子状态机测试及接口、回调、投影、前端构建验证；正式部署后分开记录生产与离线证据。

对勾只表示同事确认已人工转发微信，不代表微信实际送达或工厂接单。暂缓不取消生产订单。测试不发真实下单消息。
