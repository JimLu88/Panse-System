## 原因和实施边界

旧 `discount_availability` 是精确优惠ID的30分钟凭据；本次807d6fd是逐商品双列表终态，
不能强行转换为同种凭据或延长通用有效期。旧入口抛过期错误只说明旧凭据失效，不能说明
8件现有窗口都被占用；新列表未显示成员也不能说明原unknown提交失败。

因此采用独立、固定范围、本地报告适配，不改既有Authority或上传门：

1. 固定原request/payload/source/result SHA256及finished终态，原身份、8件102SKU、国庆窗口。
2. 复用Web-Agent纯离线覆盖验证器，从原始分页重新验证16组完整列表，不信任空数组/完成标志。
3. 在只读事务中消费现有历史账本；区分本次观察未显示已知旧优惠成员与历史提交结果。
4. 已知旧ID145761399121/145807488351、旧精确窗口才可作本地成员缺席标记；unknown无条件继续保护。
5. 输出每件仍保护的offer、claim、SKU范围；不返回可替换Authority的过滤列表，不生成价格/XLSX。
6. 相称正反测试、真实既有终态离线运行、主程序安装哈希及GitHub读回后交03。
