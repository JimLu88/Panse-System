# 飞书机器人配置指南（发图/发表格 → 自动入库）

> 目标：在飞书里 @机器人 发**图片**（订单/支付宝/采购/工厂对账/送货单截图）或发**表格文件**
> （订单/工厂对账/万师傅/物流/推广/微信账单/代付/补单/账户余额/支付宝 的 Excel/CSV），机器人
> 自动识别类型 → 弹卡片确认 → 入库，并把原文件按类型归档。

---

## 一、先在飞书开放平台建应用（约 5 分钟）

1. 打开 **open.feishu.cn → 开发者后台 → 创建企业自建应用**，填名称/图标。
2. 进应用后，**「凭证与基础信息」**里拿到 **App ID** 和 **App Secret**（待会儿填进系统）。
3. **「应用能力 → 添加机器人」**：启用「机器人」能力。
4. **「权限管理」**，添加这几个权限（搜名字勾上）：
   - `im:message`　　　　接收单聊/群里 @机器人 的消息（收图、收文件）
   - `im:resource`　　 　读取消息里的图片/文件（下载原件）
   - `im:message:send_as_bot`　以应用身份发消息（回卡片 / 更新卡片）
5. **「版本管理与发布」**创建版本并发布（**权限改了必须重新发布才生效**）。

> 之后把机器人**拉进你们的工作群**，或在飞书里**单独私聊**这个机器人。发消息时 @它。

---

## 二、把凭证填进系统

系统里：**数据工具 → 飞书**（路由 `/feishu`）：
- **App ID**、**App Secret**：必填（上一步拿的）。
- **Verification Token**、**Encrypt Key**：**只有走 Webhook（方式 B）才需要**；走长连接（方式 A，推荐）留空即可。

填完点 **保存**，再点 **测试连接** —— 显示成功/绿色就说明凭证对了。
（报 `code 10003/10014` = App ID/Secret 填错。）

---

## 三、二选一：怎么让机器人收到消息

### ✅ 方式 A：长连接（**推荐**，免公网地址、免回调、免验签）

系统主动连飞书，最省事，**不需要 DDNS / 回调地址 / Verification Token**。

1. 飞书开放平台 **「事件订阅」**：
   - 「订阅方式」选 **使用长连接接收事件**。
   - 添加事件：**`im.message.receive_v1`**（接收消息）。
   - 卡片按钮回调（`card.action.trigger`）走长连接自动接收，无需另配地址。
2. 系统侧打开开关：给 **api 服务**加环境变量 **`ENABLE_FEISHU_BOT=1`**，然后重启 api。
   - 在 `docker-compose.override.yml`（或 `docker-compose.yml`）的 `api:` 服务下加：
     ```yaml
     services:
       api:
         environment:
           - ENABLE_FEISHU_BOT=1
     ```
   - 重启：`docker compose up -d`
3. 看 api 启动日志出现 **「飞书机器人长连接已启动」** = 成功。
   （日志里出现「未配置 app_id/secret」= 第二步凭证没填好。）

### 方式 B：Webhook（需要公网地址 / 你们的 DDNS）

1. **数据工具 → 飞书** 里把 **Verification Token** 填上（飞书事件订阅页给的那个）；
   若在飞书开了「加密」，再填 **Encrypt Key**。保存。
2. 飞书 **「事件订阅」**：
   - 「订阅方式」选 **将事件发送至开发者服务器**。
   - **请求地址**填：`https://你的DDNS域名/api/feishu/webhook`
     （这个地址在 数据工具→飞书 页面有「复制」按钮，直接拿。）
   - 飞书会发一次校验（`url_verification`），系统会自动回 `challenge` → 通过。
   - 添加事件 **`im.message.receive_v1`**。
3. **卡片回调**：在「**消息卡片 → 卡片回调地址**」也填同一个 `…/api/feishu/webhook`
   （按钮点击 `card.action.trigger` 走这里）。
4. 前提：DDNS 域名 **https 可达**、防火墙放行、反向代理把 `/api/feishu/webhook` 转到 api 服务。

> 两种方式选一个就行。**先用方式 A 长连接最快**，能跑通再考虑要不要上 Webhook。

## 四、配置图片 OCR（**只有"发图片"才需要**；发 Excel/CSV 不用）

发**图片**（截图）要让 AI 看图，需配视觉模型；发**表格文件**（xlsx/csv）不需要 AI。

- 系统：**数据工具 → 管理（/admin）→ 「AI 集成 / OCR 配置」** 标签 → 配 **OCR（kind=ocr）** 的
  视觉模型：填 API Key + 模型名（要支持图像：Claude / 通义千问 Qwen-VL / 豆包 等）。
- 没配 OCR：发图会回「OCR 未配置」；但发 Excel/CSV 文件照常能用。

## 五、测试清单（发什么 → 期望）

| 发什么 | 机器人怎么回 |
|---|---|
| 千牛/淘宝**订单截图** | 「识别为订单表，确认入库？」→ 点确认 → 「✅ 处理完成：新增 N 单」 |
| **支付宝流水截图** | 识别→确认→入「支付宝(截图)」账户（长账单建议改用 CSV/Excel，更全） |
| **采购单/进货单截图** | 识别为采购单→确认→入采购（图不像采购会提示换类型） |
| **供应商送货单截图** | 「这是哪家供应商？」列出供应商 → 点选 → 入库归该供应商 |
| **工厂对账截图** | 识别为工厂对账→确认→入对账表 |
| **物流账单.xlsx** | 「识别为物流账单，确认导入？」→ 确认 → 入库 |
| **任意账单 xlsx/csv** | 按文件名+表头判类型；**认不准**就「这是哪类？」列全部类型让你点 |
| 发了不认识的文件(.pdf 等) | 「暂不支持，只认 .xlsx/.xls/.csv」 |

> 不管入库成不成，**原文件都已按类型归档**：**数据工具 → 导入档案**（`/import-archive`）可按类型筛选、下载、远程查看（经 DDNS）。归档目录与远程查看方式见 `deploy/STORAGE_归档与远程查看.md`。
> **最新更新日期**：任何入口（飞书/网页/截图）导入后，**报表/财务页的「数据新鲜度」会自动反映**（它读各表最后日期，不认入口）。

## 六、排障速查

| 现象 | 多半是 |
|---|---|
| 测试连接失败 / code 10003、10014 | App ID / App Secret 填错 |
| 发消息机器人没反应 | ① 机器人能力没开 ② `im.message.receive_v1` 没订阅 ③ 权限改了没重新发布 ④ 机器人没在群里 / 没 @ 它 ⑤（长连接）`ENABLE_FEISHU_BOT=1` 没设或没重启、日志没有「长连接已启动」 |
| 卡片按钮点了没反应 | （长连接）连接断了；（Webhook）`card.action.trigger` 卡片回调地址没配 |
| 发图回「OCR 未配置」 | 去 管理→AI 集成/OCR 配置 配视觉模型 |
| 发文件回「暂不支持」 | 只认 .xlsx / .xls / .csv；老 .xls 请在 Excel 里「另存为 .xlsx」 |
| xlsx 里长订单号/流水号对不上 | Excel 把长数字列存成了数字会丢精度 —— 长号列在 Excel 里设成「文本」格式，或直接用 CSV |

## 七、前期识别准确度小贴士
机器人对 **Excel 文件**用「文件名关键词 + 表头列名」判类型。前期你们文件名/表头还没统一时，
认不准它会**弹卡片让你点一下选类型**（不会乱入）。等文件名固定下来（比如统一叫
`6月-物流账单.xlsx`、`5月-万师傅.xlsx`），就基本全自动了。图片类（采购单等）用视觉模型判，
**置信度不够也会让你确认**，宁可多问一句也不误入。
