# AI 客服工作台 — 普通人看得懂的使用说明

## 一句话说明

这是一套装在电脑上的 **「千牛客服辅助工具」**：听到有新消息提示（或每隔一段时间），就自动 **截图聊天记录 → 识别文字 → 结合知识库 → 让 AI 写出回复 → 再自动发到聊天框**。  
需要人工接手时，会 **先发一句固定安抚话**，并 **给你手机发推送**，让你上线处理。

---

## 使用前准备（少一样都可能用不了）

1. **千牛（卖家工作台）已打开**，并且能正常聊天。  
2. **选好店铺配置文件**（YAML）：里面写了要点哪里、截哪一块图等，相当于告诉软件「千牛窗口在哪」。  
3. **在「设置」里填好**：  
   - **Claude（Anthropic）的 API Key**：不然 AI 不会写字。  
   - **至少一种手机推送**（Server酱 / PushPlus / 企业微信机器人 三选一即可）：不然「要你来接手」时你只能盯着电脑，手机不响。  
4. **DPI 缩放建议 100%**（系统显示设置里），否则点击位置容易偏。

## 界面从左到右、从上到下怎么用

### 左边三个菜单

| 菜单 | 干什么 |
|------|--------|
| **控制台** | 开关整套自动化、看状态、设「什么时候喊人」 |
| **知识库** | 看你这家店里已经录入的问答话术（表格形式） |
| **设置** | 填 API、填推送、保存后写入配置文件 |

### 控制台里几块分别是什么意思

**1）店铺与 Core**

- **选店铺 YAML**：告诉程序用哪套店铺参数（千牛窗口、截图区域等）。  
- **启动 Core**：启动「真正往千牛输入文字」的那条执行线；不启动就不能自动发消息。  
- **停止 Core**：整条执行线关掉。

**2）Jim 协同策略（可以当成「喊人工的规则」）**

- **愤怒阈值（1～4 次）**：  
  程序会从买家话里猜是不是在骂人、投诉等。若 **连续好几条都像在发火**，达到你选的次数，就认为 **必须人来接**，并 **往手机推送**，同时 **自动发一句**：「您稍等呢，我查询一下，我让主管来看一下。」  
- **强提醒**：  
  测试阶段可以打开：**每次系统跑一轮（听到提示音或兜底扫描）**，都给你手机发个通知，方便你对照是不是误触。下面日期是 **到期自动停止强提醒**，避免一直刷屏。  
- **弹窗清理**：  
  后台偶尔去尝试点「关闭 / 我知道了」之类按钮，减少广告挡屏幕。**改完后要点「保存策略」，并且重新启动「听觉流水线」才生效。**

点 **「保存策略」**：上面这些规则会写进电脑里的数据库，跟当前选的店铺绑定。

**3）一键恢复 AI**

人工在千牛里聊完后，点这里：程序会 **往上滚聊天记录 + 重新截图识字**，让 AI 重新「接上上下文」，然后继续自动回复。

**4）全自动流水线**

- **启动听觉流水线**：开始 **听千牛提示音**（音量突变），听到了就跑一轮「截图 → AI → 发消息」。  
- **兜底**：若一直没提示音，也会按你在设置里配的间隔（默认约 **10 分钟**）自动扫一轮，避免长时间不看会话。

**5）运行日志**

黑框里会刷步骤说明；看不懂也没关系，只要没有一串报错就行。

## 建议操作顺序（第一次上手）

1. 打开 **设置** → 填 API、填推送 → **保存**。  
2. 回到 **控制台** → **选择店铺 YAML**。  
3. 设好 **Jim 策略**（愤怒次数、要不要强提醒等）→ **保存策略**。  
4. 点 **启动 Core**。  
5. 再点 **启动听觉流水线**。  

接下来：有新消息提示音时，程序会自动尝试回复；要你来处理时会推送到手机。

## 还没做全、或只能「尽力而为」的功能

下面这些 **不是你没会用**，而是当前版本 **做不到完美**，心里有数即可：

| 事情 | 实际情况 |
|------|----------|
| **直接发实拍图 / 从图库点图片发出去** | 目前主要是 **用文字描述 + 发链接**；不能像人一样从相册选图发送。 |
| **识别所有官方广告并点「已读」** | 只能用简单规则 **跳过特别像广告骚扰的一句话**；不能保证每条广告都识别。 |
| **关掉所有千牛弹窗** | 只会 **偶尔尝试点前台窗口里常见的关闭按钮**，复杂广告不一定关得掉。 |
| **推送渠道** | 依赖你自己填的 Server酱 / PushPlus / 企微；填错就收不到。 |

## 术语对照（看不懂时可以翻一下）

| 说法 | 白话 |
|------|------|
| Core | 负责「真的在千牛里打字、点发送」的那套程序。 |
| 听觉流水线 / Brain | 「听到提示音或定时」→ 截图识字 → 叫 AI 写回复 → 排队发出。 |
| ManualHold / 转人工 | 程序不再自动回，留给你处理。 |
| Jim 介入 | 这里用作「需要真人客服接手」的统称：推送 + 固定安抚话 + 暂停自动回复。 |
| YAML | 店铺配置文件，里面有点哪里、截哪块图等参数。 |
| RAG / 知识库 | 从历史问答里摘相关内容，帮 AI 答得更贴店铺。 |
