## 一、项目背景与目标

### 1.1 业务背景

- 品牌名称：畔色
- 产品类型：实木定制家具（木作 + 配件）
- 销售渠道：淘宝 / 小红书 / 线下门店
- 核心需求：财务、库存、报价、订单四位一体的管理系统

### 1.2 系统目标

- 建立统一的数据入口，减少多平台手工重复录入
- 实现成本核算自动化（出厂价 → 畔色成本 → 报价）
- 支持两种报价模式：轻定制（在标准款上修改）和高定（全新设计）
- 为未来升级至旺店通 / 管易云 / 定制ERP预留数据结构

### 1.3 技术选型

| 维度 | 选择 | 说明 |
|------|------|------|
| **当前平台** | 飞书多维表格 | 零成本、多人协作、支持导出Excel |
| **升级路径1** | 飞书企业版 | 更多自动化，月费约500元 |
| **升级路径2** | 旺店通 / 管易云 | 成熟SaaS，适合年GMV 100万以上 |
| **升级路径3** | 定制开发 | 业务稳定后的终极方案 |

## 二、ERP 系统 - 18张核心表格

系统共设计 18 张表格，覆盖产品、库存、订单、财务、采购、售后全链路。

### 2.1 表格总览

| 2 | **产品定价表** | 产品 | 出厂价、木作成本、木材占比、四档利润率、四档售价（自动）、尺寸调整单价、换材差价 |

### 2.2 关键设计决策

> **图片列处理**
> - 拆分为三列：淘宝主图链接 / 小红书主图链接 / 本地图片附件
> - 飞书中本地图片列设为附件字段类型

> **工厂对账表**
> - 改为工厂下单表的汇总视图，不单独维护，避免数据不一致

> **账户余额汇总**
> - 设为只读看板，从支付宝流水自动计算，不手动填写
> - 期初余额处理：从支付宝账单导出历史记录中找到12月31日余额，或通过估算+差异调整行处理

> **库存表拆分**
> - 成品库存和配件库存各自独立建表，方便分类管理

> **已删除字段**
> - 全部录入人列已删除（用户决策）

> **订单总表扩展字段**
> - 新增：退款状态 / 退款金额 / 退款日期 / 流水号

> **支付宝流水扩展字段**
> - 新增：核销状态 / 核销类型

> **售后表扩展字段**
> - 新增：关联补单编号（与补单记录表关联）

### 2.3 定制产品处理方案

BOM表只做标准款，不为每个定制款建完整BOM。定制改动单独用「定制变更记录表（3b）」记录差价。等业务量增大后再升级。

**定制编码规则：**
- 格式：母款编码 + -C + 序号
- 示例：CBS-001-C01（CBS-001是标准款，C01是第一个定制变体）

**产品总表新增字段：**
- 父款编码（关联标准款）
- 定制类型（标准款 / 定制变体）
- 定制说明摘要

**定制变更记录表（3b）字段：每个变更部位一行，共23列，包含：**
- 变更类型（尺寸调整 / 材质替换 / 新增部位 / 删减部位）
- 变更部位名称 / 原规格 / 新规格
- 材料类型 / 数量单位 / 加价金额
- 工厂确认状态 / 设计图状态

## 四、整合报价系统

### 4.1 报价模式说明

原有两个独立报价文件已整合为一张 Excel（3个Sheet），物料单价统一管理。

| 模式 | 适用场景 | 利润率设置 |
|------|----------|------------|
| **轻定制** | 在标准款基础上调整尺寸/材质/配件 | 每个产品独立设置四档利润率，灵活应对竞争 |
| **高定报价** | 全新定制，按部位逐一填写尺寸和材料 | 固定畔色利润15%，工厂利润25% |

### 4.2 计算公式总览

> **通用公式链**

```
木材成本 + 配件成本 → 厂内总成本 → × (1+工厂利润0.25) → 工厂木作总成本 →
+ 打包/运费/安装 → 畔色总成本 → ÷ (1-利润率) → 最终报价
```

> **轻定制四档售价公式**

- 日常价 = 畔色总成本 ÷ (1 - 日常价利润率)
- 小促价 = 畔色总成本 ÷ (1 - 小促价利润率)
- 中促价 = 畔色总成本 ÷ (1 - 中促价利润率)
- 大促到手价 = 畔色总成本 ÷ (1 - 大促价利润率)

> 四档利润率每个产品独立填写（黄色格），可随时调整，售价自动更新

> **高定最终报价公式**

- 高定报价 = 畔色总成本 ÷ (1 - 0.15)

> 高定固定15%利润，不需要手动调整

## 五、已发现问题及修复记录

### 5.1 VLOOKUP 查不到单价（已修复）

**问题**：原报价表中 VLOOKUP 公式查找范围写的是 B:D 列，但实际单价库在 AN:AQ 列，两者不重叠，导致所有 VLOOKUP 返回错误。

**修复**：新表中全部改用正确的 AN:AQ 引用范围。

### 5.2 换材差价列出现乱码（已修复）

**问题**：原轻定制表中「改榉木减价」和「改黑胡桃加价」两列存储的是 Excel 公式字符串（如 `=(I3*J3)-(I3*J3)/$AP$6*$AP$9`），openpyxl 读取后将其视为纯文本，填入新表后产生 0.229... 等奇怪小数，并引发 #DIV/0! 错误。

**修复**：读取时过滤所有以 = 开头的字符串，换材差价两列改为橙色空白格，用户手动填写差价金额。参数设置表提供参考单价（榉木¥240、黑胡桃¥500、樱桃木¥300）。

### 5.3 尺寸调整单价公式逻辑（待完成）

**背景**：原表中的尺寸调整单价（长度/宽度/高度/顶柜高/立收高/下柜深/追加隔板/包装物流）每个格子都有精确公式，直接引用 AP 列的木材/岩板单价计算，单价变动时自动更新。

**现状**：当前版本中，有数值的格子沿用原始数值（静态），没有动态引用参数设置表中的单价，导致物料单价变化后数字不会自动更新。

**已分析的公式逻辑：**

| 列 | 调整项 | 公式逻辑 |
|----|--------|----------|
| V列 | 下柜深度±1cm | (下柜高×0.01×主材单价×板数 + 柜长×0.01×岩板单价) × (1+工厂利润) × (1+畔色利润) |
| W列 | 追加隔板/m² | = 主材单价（直接，不含利润） |
| T列 | 顶柜高度±1cm | (柜长×0.01×背板单价 + 柜长×0.01×玻璃单价×0.67 + 侧板面积×木材单价) × 利润系数 |
| U列 | 立收高度±1cm | (柜长×0.01×洞洞板单价 + 侧板面积×木材单价) × 利润系数 |
| R列 | 餐桌长度±1cm | (两侧木框面积×木材单价 + 台面面积×岩板单价) × 利润系数 |

> 中间尺寸行使用相邻关键行的线性插值，如：`=V81-(V81-V84)/3`，表示从2.1m到1.8m之间的2.0m、1.9m插值

## 六、填表操作指南

### 6.1 ERP系统填表顺序

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1** | 填写产品总表 | 录入所有产品基础信息，建立产品编码 |
| **2** | 填写BOM表（标准款） | 每个标准款录入物料清单，计算基准成本 |
| **3** | 填写产品定价表 | 录入工厂报价后，设置四档利润率，售价自动计算 |
| **4** | 日常录入订单总表 | 每笔订单录入后关联支付宝流水 |
| **5** | 月末核对 | 核对库存、对账工厂、检查账户余额 |

### 6.2 轻定制报价使用方法

1. 在「① 轻定制报价」Sheet筛选对应产品SKU
2. 等工厂报价后，填入 H列（出厂价）和 I列（木作成本），K列总成本自动更新
3. 根据产品定位和竞品，在 L-O列填入四档利润率（黄色格）
4. P-S列四档售价自动计算完毕，T-W列显示对应毛利率
5. 如客户要求调整尺寸，参考 X-AE列的尺寸调整单价计算报价差额
6. 如客户要求换材质，参考 AF-AG列的换材差价（需参照参数设置中的单价手填）

### 6.3 高定报价使用方法

7. 打开「② 高定报价单」Sheet，在订单信息区（A3:D6）填写客户基本信息
8. 在A列选择材料分类（木材成本/配件材料成本/工厂人工费用）
9. 在C列填写材料名称（与参数设置表名称一致），D列单价自动带出
10. 填写E列（长）、F列（宽/高）、G列（数量），H列成本价自动计算
