## 问题 3：重复回复（最重要）

### 核心规则
- 同一买家消息：**AI 最多回复 3 条**
- 相似度 > **0.75** 拒发（Jaccard 字符集）
- 买家有新回复（OCR digest 变）→ 计数重置

### 主方案：SessionReplyBudget

```python
# 新建 apps/core/orchestrator/outbound_history.py

class SessionReplyBudget:
    def __init__(self):
        self.current_buyer_digest = ""
        self.reply_count = 0
        self.recent_replies = deque(maxlen=10)

    def can_send(self, text, buyer_digest, *, bypass_dedup=False
                 ) -> tuple[bool, str]:
        if buyer_digest != self.current_buyer_digest:
            self.current_buyer_digest = buyer_digest
            self.reply_count = 0
        if self.reply_count >= 3:
            return False, "hard_limit_3_reached"
        if not bypass_dedup:
            for prev in self.recent_replies:
                if jaccard_similarity(text, prev) > 0.75:
                    return False, "similar_to_prev"
        return True, ""

    def record_sent(self, text):
        self.reply_count += 1
        self.recent_replies.append(text)
```

### 接入点
- `event_pipeline.py`：所有 `enqueue_send_text / enqueue_soothe_wait` 调用前
- `apps/mobile/orchestrator/mobile_brain_bridge.py`：同上

### 兜底
- 相似度拒发 → 日志「跳过相似回复」
- 3 次上限触达 → 暂停本会话 + 弹通知「AI 已回 3 次仍无客户响应，请人工接手」

### 验收
- 同一"在么"最多 3 条
- 买家发"什么时候发货"后计数重置

## 风险清单

1. **视觉 LLM 兜底依赖外部服务**：D:\AI\AI 视觉中心 必须启动，否则 L2 跳过、少一层保护
2. **HSV 校准必须人工触发一次**：校准前黄条可能仍 miss，落红标/L3
3. **3 次硬上限对独立短消息可能"显得不积极"**：靠 digest 差异化缓解
4. **风控 LLM 重新生成仍可能踩雷**：本地后处理 + 总上限 3 次双保险
5. **右下角小窗 OCR 兜底位置因分辨率而异**：校准对话框里多一步搞定
