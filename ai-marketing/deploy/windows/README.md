# Windows 一键启动 + 看门狗

不用记命令，双击 .bat 即可。文件放在 `deploy/windows/`，自动定位到项目根目录。

## 用法（按顺序）

1. **`1-安装.bat`** —— 只需运行一次。装依赖 + 初始化演示数据。
   - 前提：先装好 [Python 3.10+](https://www.python.org/downloads/)，安装时**勾选 "Add Python to PATH"**。
2. **`2-启动并守护.bat`** —— 日常用这个。启动服务 + 自动打开浏览器，**崩溃会自动重启**（看门狗）。关闭窗口即停止。
3. **`3-开机自启(可选).bat`** —— 想让电脑一开机就自动跑，运行一次即可；取消就删开始菜单启动项里的快捷方式。

打开后访问 **http://127.0.0.1:8000**。

## 两层看门狗（双保险）

- **程序内看门狗**（已内置）：每 60 秒自检 DB/磁盘/内存/调度器，连续 3 次异常自动重启进程（10 分钟冷却防风暴）。
- **外层看门狗**（`2-启动并守护.bat`）：进程一旦退出，5 秒后自动拉起——相当于把你 ERP 的 Docker `unless-stopped` 搬到了 Windows 上。

两者配合：内层发现"不健康"就主动退出，外层立刻把它拉起来，服务保持常驻。

## 其他启动方式（等价，按喜好选）

- **手动命令**：`python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
- **Docker**：`docker compose up -d --build`（端口 8001，自带 `restart: unless-stopped`，最省心，适合长期挂机/NAS）

## 常见问题

- **双击闪退**：多半是没装 Python 或没勾 PATH。先跑 `1-安装.bat` 看报错。
- **端口被占**：把 .bat 里的 `8000` 改成别的（如 `8010`），浏览器也用新端口。
- **中文乱码**：.bat 已设 `chcp 65001`(UTF-8)，若仍乱码用记事本另存为 UTF-8 即可。
