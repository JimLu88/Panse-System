# AI Marketing System · 交接说明（已建成全貌）

> 家具品牌「畔色/孚格」小红书+知乎内容矩阵系统。从设计稿到可运行实现已完成。
> 设计稿见 [`../docs/ai-marketing/`](../docs/ai-marketing)，本目录是实现。

## 一句话现状

**可运行的 Phase-1/2/3 完整实现**：内容生产→分发→引流→评论→数据闭环全通，49 个测试全绿，零配置（mock LLM + SQLite）即可端到端演示，配真实 LLM/采集器/飞书即转生产。**采集只读、发布与评论永远人工点发**——这是不封号的安全底线。

## 怎么跑

```bash
cd ai-marketing
pip install -r requirements.txt
python -m app.seed        # 预填: 8账号矩阵 + 20篇知乎初稿 + 5篇小红书草稿 + 竞品爆文 + 舆情
uvicorn app.main:app --reload
# 打开 http://127.0.0.1:8000  (工作台)  /  /docs (API)
```
Docker：`docker compose up -d --build`（端口 8001，数据持久化 ./data/）
测试：`python -m pytest tests/ -q`（49 例）

## 上线只需 3 步配置（界面「🔧 系统设置」里填，即时生效无需重启）

1. **采集器地址** `crawler_base_url`：指向一个 MediaCrawler/Spider_XHS 类的**只读**采集服务 → 爆文挖掘/评论管理/数据回采/舆情全部切真实数据。契约见 `app/services/data_source.py` 顶部。
   - 不想起服务？「系统设置」页有**JSON 导入**入口，把采集器导出的文件直接灌入。
2. **飞书 Webhook** `feishu_webhook_url`：看门狗告警/超期线索/到点发布/周报推送到群。
3. **真实大模型**（.env）：`LLM_PROVIDER=anthropic` + `ANTHROPIC_API_KEY`（或 openai 兼容）。
   鉴权（可选，.env）：`API_TOKEN=xxx` 开启后 /api/* 需 Bearer。

## 架构要点（service 层承载逻辑，对标 Panse-System ERP 习惯）

- `services/llm_router.py`：多 LLM 分层路由，mock 免 key 可跑，anthropic/openai 可插拔。
- `services/data_source.py`：采集适配层，真实爬虫与演示数据同契约切换。
- `services/watchdog.py`：60s 体检 + 连续3次失败 SIGTERM 自救（对标 ERP system_monitor）。
- `services/scheduler.py`：每小时养号清单/超期线索/到点提醒 + 飞书。
- `services/runtime_config.py`：DB 设置覆盖 env，界面改集成地址即时生效。
- 数据模型 16 张表（`models/`），事件溯源（ContentEvent）留痕全流程。

## 安全与合规底线（务必保持）

1. **采集只读**——爬虫只取信号，不代替你操作账号。
2. **发布/评论永远人工点发**——系统只"找机会+写好稿"，最后一步是人。固定间隔的机器行为是平台封号的首要特征。
3. **广告法**——发布前过合规自查，违禁词库每月人工增补。
4. **设备隔离**——一机一号，系统有"一机多号告警"。

## 仍需你本人做的（系统做不了）

实拍素材、真账号养号/发布/评论、办资质（甲醛检测/承重报告）、绑定真实设备、提供采集器/飞书凭证。
